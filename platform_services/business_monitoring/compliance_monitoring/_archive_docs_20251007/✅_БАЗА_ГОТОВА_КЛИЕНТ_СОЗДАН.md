## 🔗 Интеграция с MIO Manager

### Где Используется

**MIO Manager может:**

1. **При обнаружении проблемы** → Создать compliance alert
   ```python
   from integrations.compliance_monitoring_client import get_compliance_client

   compliance = get_compliance_client()

   # Problem detected → create alert
   await compliance.create_alert(
       alert_type='availability',
       severity='high',
       title='Service Down',
       message=f'{service_name} не отвечает',
       service_name=service_name,
       iso_clause='8.3'  # ISO 22301 clause
   )
   ```

2. **При нарушении ISO** → Создать nonconformity
   ```python
   await compliance.create_nonconformity(
       title='RTO exceeded',
       description='Восстановление заняло 4 часа вместо 2',
       severity='major',
       iso_clause='8.4.2',
       service_name='workflow_intelligence'
   )
   ```

3. **В SmartScheduler** → Запрашивать compliance score
   ```python
   # В daily/weekly report
   compliance_status = await compliance.get_compliance_status()

   report_data['compliance_score'] = compliance_status['compliance_score']
   report_data['active_alerts'] = compliance_status['active_alerts']
   ```

4. **В Health Checks** → Проверять доступность
   ```python
   # В SmartScheduler health checks
   compliance_health = await compliance.health_check()
   if compliance_health['status'] != 'healthy':
       # Escalate to brain
   ```

# В imports
from integrations.compliance_monitoring_client import ComplianceMonitoringClient

# В global instances
compliance_client = None

# В lifespan startup
compliance_client = ComplianceMonitoringClient(
    base_url=settings.COMPLIANCE_MONITORING_URL if hasattr(settings, 'COMPLIANCE_MONITORING_URL')
    else 'http://localhost:8779'

# В health checks (SmartScheduler)
compliance_health = await compliance_client.health_check()
health_results['compliance_monitoring'] = compliance_health

logger.info("   ✅ Compliance client closed")

## 📈 Use Cases для MIO Manager

### Use Case 1: Problem Detection → Alert

```python
# ObservationWorkflow detects problem
problem = {
    'service': 'workflow_intelligence',
    'issue': 'High latency',
    'severity': 'high'
}

# Create compliance alert
await compliance_client.create_alert(
    alert_type='performance',
    severity='high',
    title=f'{problem["service"]}: {problem["issue"]}',
    message='Response time > 1s',
    service_name=problem['service'],
    iso_clause='8.3'  # ISO 22301 clause
)
```

### Use Case 2: Daily Report → Include Compliance

```python
# SmartScheduler daily report
async def _daily_report_to_brain(self):
    # Get compliance status
    compliance = await self.compliance_client.get_compliance_status()

    report_data = {
        'compliance_score': compliance['compliance_score'],
        'active_alerts': compliance['active_alerts'],
        'open_nonconformities': compliance['open_nonconformities'],
        'pending_audits': compliance['pending_audits']
    }

    # Publish to brain
    await self.brain.publish_report('daily', report_data)
```

### Use Case 3: ISO Violation → Nonconformity

```python
# If RTO exceeded
if recovery_time > rto_target:
    await compliance_client.create_nonconformity(
        title='RTO Exceeded',
        description=f'Recovery took {recovery_time}h instead of {rto_target}h',
        severity='major',
        iso_clause='8.4.2',
        service_name=service_name,
        responsible_person='DevOps Team'
    )
```
