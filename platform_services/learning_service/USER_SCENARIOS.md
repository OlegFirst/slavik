## 📖 Scenario 1: New Employee Training Journey

### Context

**Persona:** Sarah Chen (New BCM Coordinator)

**Goal:** Complete onboarding training and build BCM foundation
**Duration:** 3 months
**Success:** Achieve Intermediate BCM competency, earn certification

```

    │
    ├─ Receive welcome email with learning portal link
    ├─ Login to Learning Dashboard
    ├─ View personalized onboarding path
    └─ Enroll in "BCM Fundamentals" (auto-enrolled)

Week 1: Foundation
    │
    ├─ Complete "BCM Fundamentals" (2 hours)
    │   ├─ Watch intro videos
    │   ├─ Read key concepts
    │   ├─ Take quiz (scored 85%)

    │
    ├─ Start "ISO 22301 Overview" (4 hours)
    │   ├─ Progress: 25% (1 hour completed)
    │   └─ Learning streak: 5 days 🔥
    │
    └─ Check Leaderboard (Rank: #47 of 150)

Week 2-4: Core Competencies
    │
    ├─ Complete "ISO 22301 Overview"
    │   └─ Earn "ISO Foundation" badge (+200 points)
    │
    ├─ Complete "Risk Assessment Basics"
    ├─ Complete "BIA Fundamentals"
    ├─ Complete "Incident Response Intro"
    │
    └─ Level up: Beginner → Learner 🎉
        └─ Unlock new training content

Week 5-8: Advanced Training
    │
    ├─ Competency Assessment triggered
    │   ├─ Current: Basic → Target: Intermediate
    │   ├─ Gaps identified: 3 areas
    │   └─ Development plan auto-generated
    │
    ├─ Enroll in gap-closing programs:
    │   ├─ "Advanced BIA Techniques" (8 hours)
    │   ├─ "Crisis Communications" (6 hours)
    │   └─ "BC Plan Development" (10 hours)
    │
    └─ Participation in "BCM Awareness Week"
        ├─ Attend webinar
        ├─ Complete campaign quiz
        └─ Earn "Awareness Champion" badge (+150 points)

Week 9-12: Certification Prep
    │
    ├─ Complete all prerequisite courses
    ├─ Enroll in "ISO 22301 Certification Prep" (40 hours)
    │   ├─ Self-paced modules
    │   ├─ Practice exams
    │   └─ Live Q&A sessions
    │
    ├─ Take certification exam (Scored 92%)
    │   └─ Pass! 🎓
    │
    └─ Receive official certification
        ├─ Certificate download
        ├─ LinkedIn sharing
        ├─ Earn "ISO Certified" badge (+500 points)
        └─ Level up: Learner → Practitioner

Final Status:
    ├─ Courses Completed: 12
    ├─ Certifications: 1 (ISO 22301 Foundation)
    ├─ Competency Level: Intermediate (Met target)
    ├─ Total Points: 2,150
    ├─ Badges Earned: 8
    ├─ Leaderboard Rank: #12 of 150
    └─ Learning Streak: 67 days 🔥🔥🔥
```
