### Запуск


**Автоматически:**
- ✅ Проверяет Docker
- ✅ Создаёт контейнер `vault-bcm`
- ✅ Запускает на порту 8200
- ✅ Настраивает Dev mode с токеном `bcm-root-token`

### Конфигурация

```bash

export VAULT_ADDR=http://localhost:8200
export VAULT_TOKEN=bcm-root-token
```

### Использование

**Python:**
```python
from vault_manager import get_vault_manager

vault = get_vault_manager(
    url="http://localhost:8200",
    token="bcm-root-token"
)

# Write secret
vault.write_secret("database/postgres", {
    "host": "localhost",
    "password": "secret123"
})

# Read secret
config = vault.read_secret("database/postgres")
print(config['password'])  # secret123
```

**CLI:**
```bash
# Store secret
vault kv put secret/api/openai key=sk-xxx

# Read secret
vault kv get secret/api/openai

# List secrets
vault kv list secret/
```

## 🔗 Интеграция с платформой

### Шаг 1: Защитить все сервисы через Gateway

Все platform-services должны быть доступны **только через Gateway**:

```
http://localhost:8000/api/v1/bia/*     → BIA Service (8012)
http://localhost:8000/api/v1/risk/*    → Risk Service (8013)
http://localhost:8000/api/v1/compliance/* → Compliance Service (8014)
...
```

### Шаг 2: Добавить JWT verification в каждый сервис

```python
# platform-services/bia-service/main.py
from fastapi import Depends, HTTPException, Header
import httpx

async def verify_token(authorization: str = Header(None)):
    """Verify JWT token via Auth Service"""
    if not authorization or not authorization.startswith("Bearer "):
        raise HTTPException(401, "Missing or invalid Authorization header")

    token = authorization.split(" ")[1]

    # Call Auth Service to verify
    async with httpx.AsyncClient() as client:
        response = await client.get(
            "http://localhost:8001/auth/me",
            headers={"Authorization": f"Bearer {token}"}
        )

    if response.status_code != 200:
        raise HTTPException(401, "Invalid token")

    return response.json()  # User info

# Protect endpoints
@app.get("/api/v1/bia/processes", dependencies=[Depends(verify_token)])
async def list_bia_processes():
    ...
```

### Шаг 3: Использовать Vault для секретов

**Вместо `.env` файлов:**
```python
# OLD - Hardcoded in .env
OPENAI_API_KEY=sk-proj-abc123...

# NEW - From Vault
from vault_manager import get_vault_manager

vault = get_vault_manager()
openai_key = vault.read_secret("api/openai")["key"]
```

**Пример интеграции в сервисе:**
```python
# platform-services/bia-service/config.py
import os
from vault_manager import get_vault_manager

class Settings:
    def __init__(self):
        # Try Vault first, fallback to env
        if os.getenv("VAULT_ENABLED") == "true":
            vault = get_vault_manager()
            self.openai_api_key = vault.read_secret("api/openai")["key"]
            self.supabase_key = vault.read_secret("database/supabase")["service_key"]
        else:
            self.openai_api_key = os.getenv("OPENAI_API_KEY")
            self.supabase_key = os.getenv("SUPABASE_SERVICE_KEY")

settings = Settings()
```

## 🔧 Troubleshooting

### Проблема: Auth Service не запускается

**Ошибка:** `No module named 'database'`

**Решение:**
```bash
# Проверить PYTHONPATH
cd /Users/MD/AI-Platform-ISO/infrastructure/security/auth
export PYTHONPATH="/Users/MD/AI-Platform-ISO/infrastructure:$PYTHONPATH"
python3 auth_service.py
```

### Проблема: Vault контейнер не запускается

**Проверить Docker:**
```bash
docker info
# Если ошибка - запустить Docker Desktop
```

**Проверить порт 8200:**
```bash
lsof -i :8200
# Если занят - убить процесс
kill -9 <PID>
```

### Проблема: JWT token invalid

**Проверить секреты:**
```bash
# Auth Service и Gateway должны использовать ОДИН И ТОТ ЖЕ JWT_SECRET!

# В infrastructure/.env
JWT_SECRET_KEY=<same-value>

# В gateway/api-gateway/.env
JWT_SECRET=<same-value>
```

## 🔐 Security Checklist

Production deployment:

- [ ] **Vault:** Migrate from Dev mode to Production mode
- [ ] **Vault:** Enable TLS (HTTPS)
- [ ] **Vault:** Setup auto-unseal (AWS KMS / Azure Key Vault)
- [ ] **Vault:** Enable audit logging
- [ ] **JWT:** Migrate from HS256 to RS256 (public/private keys)
- [ ] **JWT:** Implement token revocation (blacklist in Redis)
- [ ] **Auth:** Add MFA (TOTP / SMS)
- [ ] **Auth:** Add password reset flow
- [ ] **Auth:** Add account lockout (5 failed attempts)
- [ ] **Gateway:** Configure CORS whitelist (no wildcards)
- [ ] **Gateway:** Enable HTTPS only
- [ ] **Gateway:** Add WAF rules
- [ ] **All:** Rotate secrets every 90 days
- [ ] **All:** Enable security monitoring and alerting
