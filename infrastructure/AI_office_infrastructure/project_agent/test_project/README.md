# ISO 22301 Test Project

Business Continuity Management System demo project.

## Features
- Incident Management
- Risk Assessment
- Business Impact Analysis (BIA)
- Crisis Response Dashboard

## Architecture
- Backend: Python (Flask)
- Frontend: JavaScript (React)
- Database: PostgreSQL

## ISO 22301 Compliance
This project implements key requirements of ISO 22301:2019 standard:
- Business Continuity Policy
- Risk Assessment procedures
- Incident Response workflows
- PDCA cycle implementation

## Installation
```bash
pip install -r requirements.txt
npm install
```

## Running
```bash
python src/app.py
npm start
```
