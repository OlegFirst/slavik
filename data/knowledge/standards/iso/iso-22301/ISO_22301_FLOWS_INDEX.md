## FLOW PATTERNS

### Sequential Dependencies
```
Context (4.1) → Stakeholders (4.2) → Scope (4.3) → BCMS (4.4)
   ↓
Policy (5.2) → Objectives (6.2)
   ↓
BIA (8.2.2) + Risk (8.2.3) → Strategy (8.3) → Plans (8.4) → Exercises (8.5)
   ↓
Monitor (9.1) → Audit (9.2) → Review (9.3) → Improve (10)
```

### Cyclical Patterns
- **Annual cycles:** Context (4.1), Policy (5.2), BIA (8.2.2), Risk (8.2.3), Audit (9.2), Review (9.3)
- **Continuous cycles:** Monitoring (9.1), Communication (7.4), Awareness (7.3), Improvement (10.2)

### Feedback Loops
- Exercise → Lessons Learned → Plan Updates → Better Exercises
- Incident → After-Action → Improvements → Better Preparedness
- Audit → Corrective Actions → Better Compliance
- Monitor → Review → Improve → Better Performance
