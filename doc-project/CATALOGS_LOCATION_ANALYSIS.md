## 🎯 Итоговая рекомендация

### **РЕКОМЕНДУЕМОЕ**: `/data/catalogs`

**Почему это правильно**:

1. **Семантическая правильность**: Catalogs - это структурированные данные о системе
2. **Стандарт индустрии**: `/data` - стандартная папка для данных в проектах
3. **Расширяемость**: Можно добавить другие типы данных
4. **Организация**:
   ```
   /data/
   ├── catalogs/          # Service/System/Subsystem catalogs
   ├── configs/           # Configuration files
   ├── templates/         # Templates
   ├── schemas/           # JSON/YAML schemas
   └── fixtures/          # Test fixtures
   ```

5. **Независимость**: Данные отделены от кода и документации
6. **Версионируемость**: Легко версионировать data отдельно от кода
7. **Масштабируемость**: Проще управлять при росте проекта

## 🔧 План миграции

### Этап 1: Подготовка (30 мин)

```bash
# 1. Создать новую структуру
mkdir -p /Users/MD/AI-Platform-ISO/data/catalogs

# 2. Скопировать все каталоги
cp -r /Users/MD/AI-Platform-ISO/catalogs/* /Users/MD/AI-Platform-ISO/data/catalogs/

# 3. Проверить структуру
tree /Users/MD/AI-Platform-ISO/data/catalogs
```

### Этап 2: Обновление кода (1 час)

**Файлы для обновления**:

1. ✅ `/scripts/docs-generator/generate_docs.py`
   ```python
   # Было:
   CATALOGS_DIR = REPO_ROOT / "catalogs"

   # Стало:
   CATALOGS_DIR = REPO_ROOT / "data" / "catalogs"
   ```

2. ✅ `.github/workflows/update-docs.yml`
   ```yaml
   # Обновить пути к catalogs
   ```

3. ✅ Все markdown ссылки в `/doc-project`
   ```bash
   # Найти все ссылки
   grep -r "catalogs/" /Users/MD/AI-Platform-ISO/doc-project

   # Заменить на data/catalogs/
   ```

4. ✅ README файлы с инструкциями

### Этап 3: Тестирование (30 мин)

```bash
# 1. Тест docs generator
cd /Users/MD/AI-Platform-ISO/scripts/docs-generator
python generate_docs.py

# 2. Тест GitHub Actions (локально)
act -l

# 3. Проверка всех ссылок
```

### Этап 4: Удаление старой версии (10 мин)

```bash
# 1. Удалить старый каталог
rm -rf /Users/MD/AI-Platform-ISO/catalogs

# 2. Создать symlink для совместимости (опционально)
ln -s data/catalogs /Users/MD/AI-Platform-ISO/catalogs
```
