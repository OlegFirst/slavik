# BCM Project Management Module

## 🎯 Обзор

BCM Project Management - это интеллектуальный супермодуль для управления проектами непрерывности бизнеса (Business Continuity Management) на базе Odoo 18.0. Модуль объединяет функционал управления проектами с AI-технологиями и специализированными возможностями для BCM.

## ✨ Ключевые возможности

### 🧠 AI-Powered функционал
- **Локальный AI-ассистент** для каждого проекта
- **Интеллектуальный анализ** здоровья проектов
- **Автоматическое назначение** исполнителей задач
- **Предсказание сроков** выполнения задач
- **Обучение** на исторических данных

### 📊 BCM-специфичные типы проектов
- **Recovery Plan Implementation** - реализация планов восстановления
- **Exercise & Training** - проведение учений и тренингов
- **BCM Audit** - аудиты системы непрерывности бизнеса
- **Incident Response** - реагирование на инциденты
- **Continuous Improvement** - непрерывное улучшение
- **Risk & BIA Assessment** - оценка рисков и анализ влияния на бизнес

### 🔧 Расширенная функциональность
- **Health Monitoring** - мониторинг здоровья проектов в реальном времени
- **Smart Deadlines** - умные дедлайны с учетом критичности
- **Auto-escalation** - автоматическая эскалация критических проектов
- **Recovery Objectives** - настройка RTO, RPO, MTD для проектов восстановления
- **AI Insights** - получение инсайтов от центрального AI

## 📦 Установка

### Требования
- Odoo 18.0 Community или Enterprise
- Python 3.8+
- PostgreSQL 12+

### Зависимости
- `base` - базовая функциональность Odoo
- `project` - модуль управления проектами
- `hr` - управление человеческими ресурсами
- `hr_skills` - навыки сотрудников
- `calendar` - календарь и планирование
- `mail` - система сообщений
- `web_dashboard` - дашборды (опционально)

### Установка модуля

1. Скопируйте модуль в директорию addons:
```bash
cp -r bcm_project_management /path/to/odoo/addons/
```

2. Обновите список приложений:
```bash
./odoo-bin -d your_database -u all
```

3. Установите модуль через интерфейс Odoo или командную строку:
```bash
./odoo-bin -d your_database -i bcm_project_management
```

## 🚀 Быстрый старт

### 1. Настройка групп безопасности
После установки убедитесь, что пользователи добавлены в соответствующие группы:
- **BCM Project User** - для обычных пользователей
- **BCM Project Manager** - для менеджеров проектов

### 2. Настройка AI-коннектора (опционально)
Если у вас есть внешний AI-сервис:
```
Настройки → BCM → AI Configuration → AI Connectors
```

### 3. Создание первого BCM-проекта
```
BCM → Project Management → All Projects → Create
```

Выберите тип проекта (Recovery, Exercise, Audit и т.д.) и заполните основные поля.

## 📖 Использование

### Создание проекта восстановления
1. Перейдите в **BCM → Project Management → Recovery Plans**
2. Нажмите **Create**
3. Заполните основные данные:
   - **Name**: Название проекта
   - **BCM Type**: Recovery Plan Implementation
   - **Criticality Level**: High/Medium/Low
   - **Recovery Objectives**: RTO, RPO, MTD

### Мониторинг здоровья проектов
- **Health Score** - автоматически рассчитывается на основе:
  - Соблюдения сроков
  - Критичности просроченных задач
  - Загрузки команды
  - AI-анализа рисков

### Использование AI-помощника
- **Project Analysis** - получение инсайтов о проекте
- **Task Assignment** - AI предлагает оптимальных исполнителей
- **Duration Prediction** - прогнозирование сроков задач
- **Risk Detection** - выявление потенциальных рисков

## 🔧 Конфигурация

### AI Configuration
```xml
<!-- Настройка локального AI -->
<record id="bcm_ai_local_default" model="bcm.project.ai.local">
    <field name="name">Default Project AI Assistant</field>
    <field name="active">True</field>
</record>
```

### Automation Rules
Модуль включает автоматические правила:
- **Health Monitoring** - ежечасная проверка здоровья проектов
- **Auto-escalation** - эскалация критических проектов
- **AI Synchronization** - синхронизация с центральным AI

### Custom Fields
Добавляемые поля к стандартным моделям:

**project.project**:
- `bcm_type` - тип BCM-проекта
- `health_status` - статус здоровья
- `health_score` - числовой показатель здоровья
- `criticality_level` - уровень критичности
- `smart_deadline` - умный дедлайн
- `recovery_time_objective` - цель времени восстановления
- `ai_insights` - инсайты от AI

**project.task**:
- `bcm_task_type` - тип задачи BCM
- `ai_complexity_score` - сложность по AI
- `ai_suggested_assignee` - рекомендуемый исполнитель
