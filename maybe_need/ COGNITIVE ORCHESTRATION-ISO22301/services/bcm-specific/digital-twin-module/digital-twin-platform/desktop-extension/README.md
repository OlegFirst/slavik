# NASH 4.0 Digital Twin Platform
## Desktop Extension for Claude

Advanced Digital Twin simulation platform with 30 experiments for organizational modeling and AI-driven optimization.

## Features

### 30 Simulation Experiments
- **4 External Adapters**: SimPy, Mesa, EpiNow2, AnyLogic
- **22 Digital Twin Scenarios**: Operations, Finance, HR, Strategy
- **4 Internal Engines**: Theory of Change, Capacity Analysis, Routing, BCM

### AI-Powered Analysis
- Organizational health assessment
- Efficiency optimization
- Impact measurement
- Risk assessment
- Trend prediction

### Comprehensive Tools
- Create and manage digital twins
- Run complex simulations
- Generate detailed reports
- Optimize organizational parameters

## Installation

Simply drag and drop the `nash-digital-twin.dxt` file into Claude Desktop, or double-click to install.

## Configuration

After installation, you'll be prompted to configure:
- Organization name
- API key (optional, for full features)
- Database connection (optional, for persistence)
