### 🎯 Для команды разработчиков

| 📄 Документ | 🎯 Назначение | 👥 Целевая аудитория |
|-------------|---------------|---------------------|
| **BCM_PLATFORM_ARCHITECTURE_MAP.md** | Общая техническая архитектура, модули, зависимости | Backend разработчики, Архитекторы |
| **BCM_BUSINESS_SCENARIOS_AND_FLOWS.md** | Бизнес-сценарии, потоки данных, user journeys | Product managers, Business analysts |
