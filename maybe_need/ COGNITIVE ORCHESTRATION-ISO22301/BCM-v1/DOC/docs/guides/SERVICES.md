# BCM Platform Services

## 🔴 Обязательные сервисы (Core)
Эти сервисы ВСЕГДА нужны для работы платформы:

### PostgreSQL
- **Назначение**: Основная база данных для Odoo
- **Порт**: 5432
- **Статус**: ✅ Запущен

### Redis  
- **Назначение**: Кеширование и очереди задач
- **Порт**: 6379
- **Статус**: ✅ Запущен

### Odoo
- **Назначение**: Основная BCM платформа
- **Порт**: 8069
- **Доступ**: http://localhost:8069
- **Логин**: admin / admin
- **Статус**: ✅ Запущен

## 🟡 Важные сервисы (Integration)
Нужны для полноценной работы BCM функций:

### RabbitMQ
- **Назначение**: Обмен сообщениями между сервисами
- **Порт**: 5672 (AMQP), 15672 (Management UI)
- **Статус**: ✅ Запущен

### EventBus
- **Назначение**: Интеграция событий BCM
- **Порт**: 3001
- **Статус**: ⚠️ Опционально

### AI Orchestrator
- **Назначение**: AI функции для BCM
- **Порт**: 8000
- **Статус**: ⚠️ Опционально

## 🟢 Опциональные сервисы (Optional)

### Keycloak
- **Назначение**: Расширенная аутентификация (SSO, LDAP)
- **Порт**: 8080
- **Когда нужен**: Только для enterprise с SSO
- **Статус**: ❌ Отключен (используем простой admin/admin)

### MongoDB
- **Назначение**: NoSQL база для логов и аналитики
- **Порт**: 27017
- **Когда нужен**: Для больших объемов данных
- **Статус**: ❌ Отключен

### Prometheus + Grafana
- **Назначение**: Мониторинг и метрики
- **Порты**: 9090 (Prometheus), 3001 (Grafana)
- **Доступ**: 
  - Prometheus: http://localhost:9090
  - Grafana: http://localhost:3001 (admin/admin)
- **Когда нужны**: Для production окружения и анализа производительности
- **Статус**: ✅ Запущены (в отдельном docker-compose-monitoring.yml)

### Sim Adapter
- **Назначение**: Симуляция сценариев BCM
- **Порт**: 8002
- **Когда нужен**: Для учений и тестирования
- **Статус**: ❌ Отключен

### Ngrok
- **Назначение**: Внешний доступ через туннель
- **Когда нужен**: Для демо или удаленного доступа
- **Статус**: ❌ Отключен

## 📝 Рекомендации

### Для разработки:
```bash
./start.sh  # Только основные сервисы
```

### Для демонстрации:
```bash
./start-full.sh  # Все сервисы включая мониторинг
```

### Для production:
- Включить Keycloak для SSO
- Включить Prometheus/Grafana для мониторинга
- Настроить резервное копирование PostgreSQL
- Использовать внешний Redis кластер
