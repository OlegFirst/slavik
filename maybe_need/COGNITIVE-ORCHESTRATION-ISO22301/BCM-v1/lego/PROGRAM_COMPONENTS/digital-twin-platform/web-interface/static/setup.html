Решение проблем

Команда npx не найдена: Установите Node.js с официального сайта: nodejs.org
Claude не видит MCP сервер: Перезапустите Claude Desktop после установки
Ручная настройка для macOS: Откройте ~/Library/Application Support/Claude/claude_desktop_config.json
Ручная настройка для Windows: Откройте %APPDATA%\Claude\claude_desktop_config.json
