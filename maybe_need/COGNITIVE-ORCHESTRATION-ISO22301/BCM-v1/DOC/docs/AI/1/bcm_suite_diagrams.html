Процессы BCM (конвейер)

graph TD A[Контекст и активы] --> B[BIA (MTPD/RTO/RPO)] B --> C[Планы BCP/DRP (версии, согласования)] C --> D[Обучение и готовность персонала] D --> E[Инциденты / Реагирование] E --> F[Учения / Симуляции] F --> G[Аудит, GAP, CAPA] G --> H[KPI / Дашборды] H --> I[Management Review / Governance] I --> A
Цикл замкнут (PDCA): после MR улучшения возвращаются в контекст.

Сценарии использования (последовательности)

sequenceDiagram autonumber participant Manager as BCM Manager (Odoo) participant Orchestrator as AI Orchestrator participant BIA as BIA Engine (Ciw) participant Odoo as Odoo/bcm_bia Manager->>Odoo: Заполняет анкету BIA Odoo->>BIA: POST /compute (процессы) BIA-->>Odoo: RTO/RPO/MTPD Odoo->>Orchestrator: event: bcm.bia.completed Orchestrator-->>Manager: Черновик: обновить BCP/назначить учение Manager->>Odoo: Approve → План обновлён
sequenceDiagram autonumber participant IR as TheHive/Cortex participant Odoo as Odoo/bcm_incident participant Orchestrator as AI Orchestrator participant EX as Симулятор (JaamSim) IR-->>Odoo: case_id, статус инцидента Odoo->>Orchestrator: event: bcm.incident.opened Orchestrator-->>Odoo: Черновик коммуникаций/шагов реагирования Orchestrator->>EX: Запуск tabletop/симуляции EX-->>Odoo: Метрики реакции, lessons learned Odoo-->>Orchestrator: event: bcm.exercise.resulted Orchestrator-->>Odoo: CAPA и обновления планов в draft
Все действия ИИ проходят как draft → утверждение ответственным.
