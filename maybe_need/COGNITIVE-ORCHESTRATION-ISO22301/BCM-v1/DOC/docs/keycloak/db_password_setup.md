# Руководство по настройке пароля БД Keycloak

## Описание
Keycloak использует собственную базу данных для хранения пользователей, ролей и настроек. Пароль для этой базы данных теперь параметризован через переменные окружения.

## Настройка пароля

1. Установите значение переменной `KEYCLOAK_DB_PASSWORD` в файле `.env`:
   ```
   KEYCLOAK_DB_PASSWORD=ваш_надежный_пароль
   ```

2. Убедитесь, что это же значение используется в файле `init-keycloak-db.sh`.

3. При развертывании в production среде:
   - Используйте надежный генератор паролей для создания сложного пароля
   - Не храните пароль в репозитории или истории команд
   - Рассмотрите возможность использования Vault или другого хранилища секретов

## Проверка конфигурации

После установки пароля проверьте конфигурацию с помощью команды:

```bash
./scripts/verify-keycloak-config.sh
```

Эта команда проверит, что пароль корректно установлен во всех необходимых местах.
