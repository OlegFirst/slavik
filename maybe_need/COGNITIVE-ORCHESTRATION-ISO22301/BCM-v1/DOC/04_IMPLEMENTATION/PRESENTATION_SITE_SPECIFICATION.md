# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: ПРОФЕССИОНАЛЬНЫЙ ПРЕЗЕНТАЦИОННЫЙ САЙТ ISO 22301 BCM PLATFORM

## ОБЩИЕ ТРЕБОВАНИЯ

**Цель:** Создать профессиональный многостраничный презентационный сайт для внешних партнеров, инвесторов и потенциальных клиентов платформы ISO 22301 BCM Platform.

**Целевая аудитория:**
- Крупные корпорации и enterprise клиенты
- Партнеры по внедрению и интеграции
- Инвесторы и венчурные фонды
- Регуляторы и аудиторы
- Консалтинговые компании в области BCM

**Стиль:** Строго профессиональный, корпоративный, без эмоджи, с акцентом на технологическое превосходство и бизнес-ценность.
