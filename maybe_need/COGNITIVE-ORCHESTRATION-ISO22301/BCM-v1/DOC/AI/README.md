## 🧬 10 AI "Органов"

### 1. 🧠 AI Orchestrator (Port 8000)
**Центральный координатор**
- Маршрутизация запросов
- Координация других органов
- Мониторинг здоровья системы

### 2. 🎯 BIA Engine (Port 8082)
**BIA Impact Oracle**
- ML-оптимизация RTO/RPO
- Финансовый анализ воздействий
- Анализ каскадных рисков

### 3. 📊 Risk Advisor (Port 8086)
**Советник по рискам**
- FAIR + Monte Carlo анализ
- Предиктивная аналитика рисков
- Рекомендации по митигации

### 4. 📄 Document Processor (Port 8083)
**Обработчик документов**
- Классификация документов
- Извлечение ключевых концепций
- NLP анализ

### 5. ✅ Compliance Checker (Port 8084)
**Проверка соответствия**
- ISO 22301 gap analysis
- Compliance scoring
- Evidence management

### 6. 🎭 Scenario Generator (Port 8085)
**Генератор сценариев**
- AI-powered scenario generation
- Exercise management
- Learning from outcomes

### 7. 🏥 Incident Classifier
**Классификатор инцидентов**
- ML классификация
- Severity prediction
- Response recommendations

### 8. 🧬 Lifecycle Monitor
**Мониторинг жизненного цикла**
- System health monitoring
- Performance tracking
- Predictive maintenance

### 9. 🔄 PDCA Orchestrator
**Оркестратор PDCA**
- Plan-Do-Check-Act automation
- Continuous improvement tracking
- Management review coordination

### 10. 🌐 MCP Server (Port 8087)
**Model Context Protocol**
- Claude Desktop integration
- Anthropic AI integration
- Chat-based BCM consultation

## 🛠️ Технологии

### AI Frameworks
- **Anthropic Claude** (Sonnet, Opus)
- **Local LLM** (Gemma3 для сценариев)
- **scikit-learn** (ML модели)
- **NLTK** (NLP)

### Infrastructure
- **FastAPI** - API framework
- **PostgreSQL** - Data persistence
- **Redis** - Caching
- **RabbitMQ** - Message queue

### Integration
- **MCP (Model Context Protocol)** - Anthropic integration
- **EventBus** - Internal communication
- **REST API** - External communication
