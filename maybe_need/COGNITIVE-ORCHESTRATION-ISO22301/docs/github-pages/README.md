# BCM Platform GitHub Pages Site

Professional presentation website for the ISO 22301 BCM Platform, designed for partners and stakeholders.

## Structure

- `index.md` - Main landing page with platform overview
- `architecture.md` - System architecture with Mermaid diagrams
- `modules.md` - Comprehensive module descriptions
- `technology.md` - Technology stack details
- `roadmap.md` - Implementation roadmap and vision

## Deployment

### Local Development

1. Install Jekyll:
```bash
gem install bundler jekyll
```

2. Install dependencies:
```bash
bundle install
```

3. Run locally:
```bash
bundle exec jekyll serve
```

4. View at: http://localhost:4000/ISO-22301

### GitHub Pages Deployment

1. Push to GitHub repository
2. Enable GitHub Pages in repository settings
3. Select source branch (main or gh-pages)
4. Site will be available at: https://seh-foundation.github.io/ISO-22301
