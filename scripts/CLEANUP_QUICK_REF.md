# 🚀 Safe Cleanup - Quick Reference

## Быстрый старт

```bash
# 1. Сухой прогон (только отчет)
./scripts/safe-cleanup.sh

# 2. Применить изменения
./scripts/safe-cleanup.sh --apply

# 3. Только валидация
./scripts/safe-cleanup.sh --validate

# 4. Подробный вывод
./scripts/safe-cleanup.sh -v
```

---

## Что делает (одной строкой)

✅ **СОХРАНЯЕТ:** русский язык, Unicode, эмодзи, AI упоминания, архивы
🧹 **ОЧИЩАЕТ:** .bak, .tmp, .DS_Store, валидирует JSON/YAML

---

## Типичные сценарии

### Перед коммитом
```bash
git add .
./scripts/safe-cleanup.sh --apply
git commit -m "feat: новая фича"
```

### Еженедельная очистка
```bash
./scripts/safe-cleanup.sh --apply
cat .cleanup-report/cleanup-report-*.md
```

### Проверка перед PR
```bash
./scripts/safe-cleanup.sh --validate
```

---

## Отчет

```bash
# Открыть последний отчет
cat .cleanup-report/cleanup-report-*.md

# Найти большие файлы
grep "Large Files" .cleanup-report/cleanup-report-*.md -A 20

# Проверить ошибки валидации
grep "invalid" .cleanup-report/cleanup-report-*.md
```

## Что НЕ трогает

```
✅ НАЧАТЬ_С_ЭТОГО.md          - русское имя
✅ "Generated by Claude"       - AI упоминание
✅ _archive/                   - архив
✅ docs/                       - документация
✅ 🔐 эмодзи в коде            - Unicode
✅ ВСМ-colleagues/             - кириллица в путях
```

---

## Что удаляет

```
🧹 *.bak                       - backup файлы
🧹 *.tmp, *.temp               - временные файлы
🧹 .DS_Store, Thumbs.db        - системные метаданные
🧹 *.swp, *.swo, *~            - editor временные файлы
🧹 *.orig, *.rej               - git merge артефакты
```

---

## Exit codes

```bash
0  # Успех
1  # Validation failed (invalid JSON/YAML)
```

## Флаги

| Флаг | Описание |
|------|----------|
| `--apply` | Применить изменения |
| `--validate` | Только валидация |
| `-v`, `--verbose` | Подробный вывод |
| `-h`, `--help` | Помощь |

## FAQ одной строкой

**Q: Безопасно?**
A: ДА. По умолчанию dry-run (только отчет).

**Q: Удалит русские файлы?**
A: НЕТ. Сохраняет все имена и контент.

**Q: Удалит упоминания Claude?**
A: НЕТ. Сохраняет весь контент.

**Q: Rollback?**
A: `git checkout -- <file>` или `git reset --hard HEAD`
