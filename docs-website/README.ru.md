## 🚀 Задеплоить на GitHub Pages (чтобы партнеры могли открыть онлайн)

```bash
cd /Users/MD/AI-Platform-ISO/docs-website

# 1. Добавить все файлы
git init
git add .
git commit -m "Professional docs website"

# 2. Создать репозиторий на GitHub
# Зайди на github.com → New repository → "AI-Platform-ISO-docs"

# 3. Пушнуть
git remote add origin https://github.com/[твой-username]/AI-Platform-ISO-docs.git
git push -u origin main

# 4. Включить GitHub Pages
# Settings → Pages → Source: GitHub Actions → Save
```

Через 2-3 минуты сайт будет доступен по адресу:
**https://[твой-username].github.io/AI-Platform-ISO-docs/**
