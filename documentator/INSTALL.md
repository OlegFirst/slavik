# Documentator - Easy Setup Guide

Generate reports from templates using Claude Desktop in 3 simple steps!

## Quick Install

### Step 1: Install via NPM
```bash
npm install -g @anthropic/documentator
```

### Step 2: Run Setup
```bash
documentator-setup
```
This will:
- Create `~/projects/` directory
- Add example project with template
- Show you the Claude Desktop configuration

### Step 3: Add to Claude Desktop

1. **Find your Claude config file:**
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`

2. **Add this configuration:**
```json
{
  "mcpServers": {
    "documentator": {
      "command": "documentator"
    }
  }
}
```

3. **Restart Claude Desktop**

## Create Your Own Projects

1. **Create a new project folder:**
   ```
   ~/projects/my-weekly-reports/
   ```

2. **Add a template file** `weekly-template.md`:
   ```markdown
   # Weekly Report: {{week}}
   
   **Author:** {{author}}
   **Date:** {{date}}
   
   ## Completed Tasks
   {{#each tasks as task}}
   - ✅ {{task}}
   {{/each}}
   
   ## Notes
   {{notes}}
   ```

3. **Use in Claude:**
   ```
   Create a report from project "my-weekly-reports" using template "weekly-template" with data:
   - week: "Week of Jan 15-21"
   - author: "John Doe"
   - tasks: ["Finished API integration", "Updated documentation", "Fixed 3 bugs"]
   - notes: "Great progress this week!"
   ```

## Template Syntax

- `{{variable}}` - Simple variable
- `{{variable|default}}` - Variable with default value  
- `{{#if condition}}...{{/if}}` - Conditional content
- `{{#each array as item}}...{{/each}}` - Loop through array

## Troubleshooting

**"documentator command not found"**
- Make sure you installed globally with `-g` flag
- Try restarting your terminal

**"No projects found"**
- Run `documentator-setup` again
- Check that `~/projects/` directory exists

**Claude doesn't respond**
- Restart Claude Desktop after config changes
- Check that config JSON is valid
