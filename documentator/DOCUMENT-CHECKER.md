# Document Checker - Перевірка та виправлення документів

**Document Checker** - це потужна система перевірки орфографії, граматики та пунктуації для текстових документів, інтегрована в Documentator сервіс Digital Office платформи.

## 🎯 Основні можливості

### ✅ Типи перевірок

**📝 Орфографія:**
- Перевірка написання слів українською та англійською мовами
- Інтелектуальні пропозиції виправлень на основі відстані Левенштейна
- Підтримка технічної термінології

**📚 Граматика:**
- Правила української граматики (прийменники, відмінки)
- Англійські граматичні конструкції
- Виправлення типових помилок ("its/it's", "should of/should have")

**✏️ Пунктуація:**
- Множинні пробіли
- Неправильне розміщення розділових знаків
- Пробіли перед комами, крапками, знаками питання

**🏗️ Збереження структури:**
- Markdown заголовки, списки, посилання
- Блоки коду (не перевіряються)
- HTML теги та атрибути
- Форматування (жирний, курсив, код)

## 🚀 Використання через Claude

### Перевірка файлу:
```
Перевіри документ test-document.md використовуючи documentator:check_document
```

### Перевірка тексту:
```
Перевіри цей текст:
"В результаті аналізу ми прийшли к висновку що система працює ефективно."
```

### Додаткові опції:
```
Перевіри файл README.md без автоматичного виправлення та збережи в новий файл
```

## 🛠️ MCP команда

**`documentator:check_document`** - перевіряє та виправляє помилки у документах

### Параметри:

| Параметр | Тип | Опис |
|----------|-----|------|
| `filePath` | string | Повний шлях до файлу для перевірки |
| `textContent` | string | Текст для перевірки (альтернатива filePath) |
| `fileExtension` | string | Розширення файлу (.md, .txt, .html) |
| `autoFix` | boolean | Автоматично виправляти помилки (за замовчуванням: true) |
| `saveBackup` | boolean | Створювати резервну копію (за замовчуванням: true) |
| `outputPath` | string | Шлях для збереження виправленого файлу |

## 📊 Результат перевірки

### Звіт містить:

**📊 Підсумок:**
- Загальна кількість помилок
- Кількість автоматично виправлених помилок
- Тип документу (markdown, text, html)

**🔍 Помилки за типами:**
- 📝 Орфографія: кількість
- 📚 Граматика: кількість  
- ✏️ Пунктуація: кількість
- 🎨 Стиль: кількість

**📋 Структура документу:**
- 📑 Заголовків: кількість
- 📋 Списків: кількість
- 💻 Блоків коду: кількість
- 🔗 Посилань: кількість
- ✨ Форматування: кількість

**🚨 Детальний список помилок:**
- Номер та рядок помилки
- Рівень серйозності (🟡 низький, 🟠 середній, 🔴 високий)
- Оригінальний текст та виправлення
- Опис помилки

## ⚙️ Налаштування

**Підтримувані формати:**
- `.md` / `.markdown` - Markdown документи
- `.txt` - Звичайний текст
- `.html` / `.htm` - HTML документи

**Автоматичне виправлення:**
- ✅ Пунктуаційні помилки (множинні пробіли, неправильні знаки)
- ✅ Граматичні помилки високого рівня
- ❌ Орфографічні помилки (лише пропозиції)
- ❌ Граматичні помилки низького рівня

**Резервні копії:**
- Створюються файли з розширенням `.backup`
- Зберігають оригінальний вміст документу
- Можна відключити параметром `saveBackup: false`

## 🧠 Алгоритми перевірки

### Граматичні правила

**Українські:**
- `в коли` → `в якому`
- `в які` → `в яких`  
- `з-за того що` → `через те що`
- `від самого початку` → `з самого початку`
- `прийти к висновку` → `дійти висновку`
- `в подальшому` → `надалі`

**Англійські:**
- `it's own` → `its own`
- `your welcome` → `you're welcome`
- `should of` → `should have`
- `could of` → `could have`

### Орфографічна перевірка

**Алгоритм відстані Левенштейна:**
- Максимальна відстань: 2 символи
- Мінімальна довжина слова: 3 символи
- Підтримка української та англійської розкладок

**Словники:**
- Українська технічна термінологія
- Англійська IT термінологія
- Розширюваний базовий словник

### Збереження структури

**Markdown елементи:**
```markdown
# Заголовки → зберігаються
**жирний текст** → зберігається форматування  
`код` → не перевіряється
[посилання](url) → перевіряється тільки текст
```

**Блоки коду:**
```
```typescript
// цей код не перевіряється
const test = "example";
```
