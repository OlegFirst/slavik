# Простий приклад використання Documentator

## Створення проекту

1. **Створіть папку проекту:**
   ```
   projects/my-reports/
   ```

2. **Додайте шаблон звіту:**
   
   Створіть файл `projects/my-reports/weekly-report.md`:
   ```markdown
   # Тижневий звіт: {{title}}

   **Автор:** {{author}}
   **Тиждень:** {{week}}
   **Дата:** {{date|{{new Date().toLocaleDateString('uk-UA')}}}}

   ## Виконані завдання

   {{#if tasks}}
   {{#each tasks as task}}
   - ✅ {{task}}
   {{/each}}
   {{#else}}
   *Завдань не виконано*
   {{/if}}

   ## Коментарі

   {{comments|Без коментарів}}
   ```

## Використання в Claude

1. **Перегляд проектів:**
   ```
   Покажи мені всі проекти
   ```

2. **Аналіз проекту:**
   ```
   Проаналізуй проект "my-reports"
   ```

3. **Створення звіту:**
   ```
   Створи звіт з проекту "my-reports" використовуючи шаблон "weekly-report" з такими даними:
   - title: "Розробка CRM"
   - author: "Олексій Петров" 
   - week: "15-21 січня 2024"
   - tasks: ["Створив API для клієнтів", "Налаштував базу даних", "Написав тести"]
   - comments: "Всі завдання виконано вчасно"
   ```

## Синтаксис шаблонів

- `{{variable}}` - проста змінна
- `{{variable|default}}` - змінна з значенням за замовчуванням
- `{{#if condition}}...{{/if}}` - умовний блок
- `{{#each array as item}}...{{/each}}` - цикл по масиву
