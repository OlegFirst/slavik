# PM Service - Просунутий генератор контенту

**PM Service** - це потужний сервіс генерації текстового контенту з професійними системними промптами для PR та проект-менеджменту, інтегрований у Digital Office платформу.

## 🎯 Основні функції

### 📰 Press Release (`release`)
Створення професійних прес-релізів з використанням потужного системного промпту, який включає:
- Структуру прес-релізу (заголовок, підзаголовок, лід-абзац, основний текст, цитати)
- Техніки newsjacking та SEO-оптимізації
- Критерії якості та читабельності
- Автоматичне форматування в Markdown

### 📈 Project Points (`point`)  
Короткі, але змістовні повідомлення про проміжні досягнення проектів:
- Структурований виклад досягнень
- Метрики та показники прогресу
- Зв'язок з бізнес-цінністю
- Мотивація команди та прозорість для стейкголдерів

## 🚀 Використання через Claude

### Створення прес-релізу:
```
Створи прес-реліз використовуючи pm:release
```

### Створення project point:
```
Створи короткий звіт про досягнення використовуючи pm:point
```

### Перегляд доступних промптів:
```
Покажи всі доступні промпти PM сервісу
```

## 🛠️ Команди MCP

| Команда | Опис |
|---------|------|
| `pm:release` | Створити професійний прес-реліз |
| `pm:point` | Створити project point |
| `pm:list_prompts` | Показати всі промпти |
| `pm:get_prompt_info` | Інформація про промпт |
| `pm:generate_custom` | Генерація з будь-яким промптом |

## 📝 Інтерактивний режим

PM сервіс автоматично запускає інтерактивний режим, де питає необхідну інформацію:

### Для прес-релізу:
- 🔴 **Обов'язкові поля:**
  - Назва компанії
  - Тип анонсування
  - Основна новина
  - Ключові переваги
  - Цільова аудиторія

- ⚪ **Опціональні поля:**
  - Цитата від керівництва
  - Статистика/цифри
  - Місце події
  - Інформація про партнерів
  - Терміни реалізації
  - Background компанії
  - Контактна інформація
  - SEO ключові слова

### Для project point:
- 🔴 **Обов'язкові поля:**
  - Назва проекту
  - Конкретне досягнення
  - Вплив на проект
  - Етап проекту

- ⚪ **Опціональні поля:**
  - Метрики та цифри
  - Внесок команди
  - Виклики та рішення
  - Наступні кроки
  - Бізнес-цінність
  - Бюджетні показники

## 🎨 Системні промпти

### Press Release Prompt
```
Професійний копірайтер та PR-спеціаліст з 10+ роками досвіду...

ПРИНЦИПИ СТВОРЕННЯ ПРЕС-РЕЛІЗУ:
1. СТРУКТУРА (обов'язково дотримуватися)
2. СТИЛЬ НАПИСАННЯ (активний стан, короткі речення)
3. NEWSJACKING ТЕХНІКИ (зв'язок з трендами)
4. КРИТЕРІЇ ЯКОСТІ (новинність, актуальність, унікальність)

ВИМОГИ ДО КОНТЕНТУ:
- Заголовок: 60-80 символів
- Лід-абзац: 25-35 слів
- Загальний обсяг: 300-500 слів
- Читабельність: рівень 8-10 класу
```

### Project Point Prompt
```
Досвідчений проект-менеджер та комунікаційний спеціаліст...

ПРИНЦИПИ СТВОРЕННЯ PROJECT POINT:
1. СТРУКТУРА ПОВІДОМЛЕННЯ
2. ТОНАЛЬНІСТЬ ТА СТИЛЬ (позитивний, конкретні факти)
3. КЛЮЧОВІ ЕЛЕМЕНТИ (чіткість, фокус на результатах)
4. ПСИХОЛОГІЧНІ АСПЕКТИ (мотивація, довіра)

ВИМОГИ ДО КОНТЕНТУ:
- Загальний обсяг: 100-250 слів
- Заголовок: до 60 символів
- Обов'язкове включення метрик/цифр
```

## 📁 Вихідні файли

PM сервіс автоматично зберігає згенерований контент у:
- **Директорія:** `output/pm/`
- **Формат:** Markdown (`.md`)
- **Назва файлу:** `{promptId}-{timestamp}.md`

## Нова веха у розвитку для IT-спеціалістів

**Київ, 9 вересня 2024** — Компанія представила революційне AI-рішення...

Завершено інтеграцію з платіжною системою, протестовано на 100 транзакціях

Прискорює процес оплати на 40%, покращує користувацький досвід

### 📊 Ключові показники
85% готовності, 3 дні випередження графіку, 12% під бюджетом

## 🛡️ Валідація даних

PM сервіс включає потужну систему валідації:
- Перевірка обов'язкових полів
- Валідація типів даних
- Контроль довжини тексту
- Перевірка форматів (дата, email, тощо)
- Валідація опцій для select полів

## 🚀 CLI команди

```bash
# Перевірка статусу PM сервісу
npm run cli services status pm

# Включення/відключення PM сервісу  
npm run cli services enable pm
npm run cli services disable pm

# Запуск/зупинка PM сервісу
npm run cli services start pm
npm run cli services stop pm
```
