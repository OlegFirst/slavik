Частые вопросы

Какова стоимость платформы?

AI-Platform-ISO - некоммерческий проект. Для медицинских и гуманитарных организаций доступна бесплатная лицензия. Для коммерческих организаций стоимость определяется индивидуально в зависимости от масштаба и требований.

Сколько времени занимает внедрение?

Типичное внедрение занимает 25-30 дней от регистрации до полного запуска. Это включает настройку организации, интеграцию данных, обучение команды и валидацию.

Можно ли интегрировать с существующими системами?

Да, платформа имеет коннекторы для популярных систем (Odoo, Salesforce, HubSpot) и открытый REST API для custom интеграций. Поддерживаются webhooks и event-driven архитектура.

Где хранятся данные?

Данные хранятся в PostgreSQL (Supabase) с полным шифрованием. Возможны варианты размещения: облако (EU/US регионы), on-premise, гибридная архитектура. Полное соответствие GDPR.

Какая поддержка предоставляется?

Для партнеров доступна техническая поддержка по email, документация, community форум. Для критичных проектов возможна поддержка 24/7 и выделенный менеджер.

Можно ли получить демо-доступ?

Да, для потенциальных партнеров доступен демо-стенд с тестовыми данными. Заполните форму обратной связи с выбором "Запрос демонстрации".
