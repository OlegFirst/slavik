# Техническое Задание: Интерфейс Проектного Менеджера

**Project Manager Control Interface - Technical Specification**

**Дата**: 2025-10-09
**Версия**: 1.0
**Статус**: Утверждено к разработке

---

## 1. Общее Описание

### 1.1 Назначение

Создать полнофункциональный веб-интерфейс для **Проектного Менеджера**, который обеспечивает:

- ✅ Максимальную настройку всех параметров системы
- ✅ Запуск проверок соответствия (6 приоритетов)
- ✅ Детальную отчетность в реальном времени
- ✅ Ручное управление сервисами
- ✅ Визуализацию состояния системы
- ✅ Управление конфигурацией
- ✅ История изменений и аудит

### 1.2 Целевая Аудитория

- **DevOps инженеры** - управление инфраструктурой
- **Системные администраторы** - контроль соответствия
- **Проектные менеджеры** - отчетность и планирование
- **Разработчики** - диагностика и тестирование

### 1.3 Технологический Стек

**Backend**:
- FastAPI (Python 3.11+)
- SQLAlchemy (БД для истории и конфигурации)
- WebSocket (real-time обновления)
- Celery (фоновые задачи)
- Redis (кэш + очереди)

**Frontend**:
- Next.js 14+ (React)
- TypeScript
- TailwindCSS + shadcn/ui
- Recharts (графики)
- React Query (состояние)
- WebSocket (real-time)

## 3. Нефункциональные Требования

### 3.1 Производительность

- **Время загрузки главной страницы**: < 2 секунд
- **Время выполнения проверок**: < 5 секунд для критичных, < 15 секунд для всех
- **Обновление real-time данных**: < 1 секунды задержки
- **Поддержка одновременных пользователей**: до 50
- **История**: хранение минимум 30 дней

### 3.2 Безопасность

- **Аутентификация**: JWT tokens + OAuth2
- **Авторизация**: Role-based access control (RBAC)
  - Admin: Полный доступ
  - DevOps: Управление сервисами, проверки
  - Viewer: Только просмотр
- **Аудит**: Логирование всех действий пользователей
- **Шифрование**: HTTPS обязателен, TLS 1.3+
- **Secrets**: Хранение в HashiCorp Vault или переменных окружения

### 3.3 Масштабируемость

- **Горизонтальное масштабирование**: Backend должен поддерживать запуск нескольких инстансов
- **Кэширование**: Redis для кэширования часто запрашиваемых данных
- **Очереди задач**: Celery для фоновых проверок
- **БД**: PostgreSQL с возможностью read replicas

### 3.4 Доступность

- **Uptime**: 99.9% (8.76 часов downtime в год)
- **Health checks**: Каждые 30 секунд
- **Auto-recovery**: Автоматический перезапуск при падении
- **Backup**: Ежедневное резервное копирование конфигурации и истории

### 3.5 Совместимость

- **Браузеры**:
  - Chrome 90+
  - Firefox 88+
  - Safari 14+
  - Edge 90+
- **Разрешения экрана**: 1920x1080 минимум (оптимизация для 4K)
- **Мобильные устройства**: Адаптивный дизайн (опционально)

## 8. Риски и Ограничения

### 8.1 Риски

1. **Производительность при большом количестве сервисов**
   - Митигация: Пагинация, виртуализация списков, ленивая загрузка

2. **WebSocket может терять соединение**
   - Митигация: Автоматическое переподключение, fallback на polling

3. **Prometheus/Grafana могут быть недоступны**
   - Митигация: Graceful degradation, кэширование последних данных

4. **Сложность настройки для новых пользователей**
   - Митигация: Wizard при первом запуске, дефолтные настройки

### 8.2 Ограничения

- Поддержка только Linux/macOS для backend (lsof)
- Максимум 100 сервисов (оптимизация UI)
- История хранится максимум 90 дней
- Не поддерживается кластерное развертывание в MVP
