async def save_to_disk(self):

## 📊 Prometheus Metrics (TSDB)

### Location
```
/var/lib/docker/volumes/prometheus_data/_data/
```

### What's stored
- All scraped metrics from all services
- Time-series data with timestamps
- Retention: 30 days (configurable)

### Size
- ~1-2 GB per week (depends on scrape frequency and cardinality)

### Backup Strategy
```bash
# Snapshot Prometheus data
docker exec bcm-prometheus promtool tsdb create-blocks-from openmetrics /prometheus

# Copy volume
docker run --rm -v prometheus_data:/data -v $(pwd):/backup alpine tar czf /backup/prometheus_backup_$(date +%Y%m%d).tar.gz /data
```

### Query from CLI
```bash
# Latest value
curl -s 'http://localhost:9090/api/v1/query?query=up' | jq '.data.result[] | {job: .metric.job, value: .value[1]}'

# Time range
curl -s 'http://localhost:9090/api/v1/query_range?query=automation_service_coverage&start=2025-10-03T00:00:00Z&end=2025-10-03T23:59:59Z&step=1h' | jq '.data.result'
```

## 🐳 Docker Container Logs

### Location
```
/var/lib/docker/containers/[container-id]/[container-id]-json.log
```

### Access
```bash
# View logs
docker logs bcm-prometheus -f

# Last 100 lines
docker logs --tail 100 bcm-prometheus

# Logs since 1 hour ago
docker logs --since 1h bcm-prometheus

# Export to file
docker logs bcm-prometheus > prometheus_logs_$(date +%Y%m%d).log
```

### Rotation
- Docker automatically rotates logs
- Default: 10 MB max size, 3 files
- Configure in `/etc/docker/daemon.json`:
```json
{
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}
```

async def startup_event():

    snapshot_file = f"{Config.COMPLIANCE_DATA_DIR}/backups/compliance_snapshot_latest.json"
    if os.path.exists(snapshot_file):
        async with aiofiles.open(snapshot_file, 'r') as f:
            data = json.loads(await f.read())
            for alert_id, alert_data in data.get('alerts', {}).items():
