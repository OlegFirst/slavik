## 🎯 Key Concepts in 60 Seconds

### 4-Level Hierarchy

```
L1: Service Level (62 services)
    ├─ Platform services (46): Database, API, Security...
    └─ User applications (16): Portal, Modules...

L2: Subsystem Level (12 subsystems)
    └─ Groups of related services working together

L3: Functional System Level (19 systems)
    └─ Purpose-based systems: Startup, Resilience, Security...

L4: User Workflow Level (Variable)
    └─ Real user journeys: "Create BIA", "Respond to incident"...
```

### 5 Golden Standards

Template files that generate scenarios automatically:
- `golden_standard_l1.yaml` → 46 platform services
- `golden_standard_l1_application.yaml` → 16 user apps
- `golden_standard_l2.yaml` → 12 subsystems
- `golden_standard_l3.yaml` → 19 functional systems
- `golden_standard_l4.yaml` → User workflows (AI-generated)

### The Magic: Continuous Improvement

```
Execute Scenario → Analyze Results → Predict Issues →
Decide Action → Improve Scenario → Archive Old Version
     ↑                                                ↓
     └────────────────────────────────────────────────┘
                    Repeat Forever
```

## 🔄 How It Works

### 1. Initial Generation (Automated)

```bash
# Scenario Manager starts
$ scenario-manager generate --all

# Reads platform catalogs
Reading SERVICE_CATALOG_DETAILED.yaml (46 services)...
Reading USER_APPLICATIONS_CATALOG.yaml (16 apps)...
Reading SUBSYSTEMS_CATALOG.yaml (12 subsystems)...
Reading SYSTEMS_CATALOG.yaml (19 systems)...

# Generates scenarios
Generating L1 platform scenarios... 46/46 ✓
Generating L1 application scenarios... 16/16 ✓
Generating L2 subsystem scenarios... 12/12 ✓
Generating L3 system scenarios... 19/19 ✓

# Results
Total scenarios generated: 652
Time elapsed: 4h 15m
Stored in: scenario_intelligence.scenarios table
Status: Ready for execution
```

### 2. Execution (Continuous)

```bash
# Execute all L1 scenarios daily
$ scenario-manager execute --level 1 --schedule "0 2 * * *"

# Execute L3 scenarios weekly
$ scenario-manager execute --level 3 --schedule "0 2 * * 0"

# Execute specific scenario on-demand
$ scenario-manager execute --id "l1-service-mio-manager"
```

### 3. Improvement (AI-Powered)

```
[Scenario executes] → [Failure detected] → [EventBus notification]
         ↓
[MIO Manager observes] → [Analytics Specialist analyzes]
         ↓
[Predictive Service forecasts] → [AI Orchestration decides]
         ↓
[Project Agent creates task] → [Scenario Manager improves]
         ↓
[New version saved] → [Old version archived]
```

## 🎯 Quick Commands (Future)

```bash
# Generate scenarios
scenario-manager generate --level 1              # L1 only
scenario-manager generate --level 2              # L2 only
scenario-manager generate --all                  # All levels

# Execute scenarios
scenario-manager execute --id <scenario_id>      # Single scenario
scenario-manager execute --level 1               # All L1
scenario-manager execute --system resilience     # All for system

# Improve scenarios
scenario-manager improve --id <scenario_id>      # Manual improve
scenario-manager improve --auto                  # Auto improve all

# View results
scenario-manager results --id <scenario_id>      # Single result
scenario-manager results --level 1 --last 7d     # L1 last 7 days
scenario-manager results --failed                # All failures

# Statistics
scenario-manager stats                           # Overall stats
scenario-manager stats --level 3                 # L3 stats
scenario-manager health                          # System health
```
