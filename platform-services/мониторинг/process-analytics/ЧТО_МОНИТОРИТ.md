# 🔍 Process Analytics - Что Именно Мониторит?

**Date:** 2025-10-08
**Question:** process-analytics = БИЗНЕС мониторинг... но ЧТО конкретно?

---

## 🎯 TL;DR

**Process Analytics НЕ мониторит серверы!**

Мониторит **ВЫПОЛНЕНИЕ БИЗНЕС-ПРОЦЕССОВ** BCM платформы:
- BIA Workflow (Business Impact Analysis)
- Risk Assessment Workflow
- Compliance Audit Workflow
- Incident Response Workflow
- etc.

**Аналогия:** Как Google Analytics следит за действиями пользователей на сайте, так Process Analytics следит за выполнением BCM workflows.

---

## 📊 Database Schema

```sql
-- Process Executions (top-level)
CREATE TABLE process_executions (
    id UUID PRIMARY KEY,
    process_id VARCHAR,      -- 'bia_workflow', 'risk_assessment_workflow'
    execution_id VARCHAR,    -- 'exec_123'
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    duration_minutes FLOAT,
    status VARCHAR,          -- 'completed', 'failed', 'in_progress'
    executed_by VARCHAR,     -- 'bia_specialist', 'risk_analyst'
    metadata JSONB
);

-- Process Events (detailed steps)
CREATE TABLE process_events (
    id UUID PRIMARY KEY,
    execution_id UUID REFERENCES process_executions,
    event_type VARCHAR,      -- 'step_completed', 'step_started', 'error'
    step_name VARCHAR,       -- 'data_collection', 'impact_analysis'
    timestamp TIMESTAMP,
    duration_minutes FLOAT,
    actor VARCHAR,           -- who/what performed this step
    data JSONB               -- step-specific data
);

-- Process Patterns (discovered patterns)
CREATE TABLE process_patterns (
    id UUID PRIMARY KEY,
    process_id VARCHAR,
    pattern_type VARCHAR,    -- 'sequence', 'timing', 'resource'
    pattern_name VARCHAR,
    frequency INTEGER,       -- how often seen
    confidence FLOAT,        -- confidence score
    pattern_data JSONB
);

-- Process Insights (analysis results)
CREATE TABLE process_insights (
    id UUID PRIMARY KEY,
    process_id VARCHAR,
    insight_type VARCHAR,    -- 'bottleneck', 'deviation', 'optimization'
    severity VARCHAR,        -- 'high', 'medium', 'low'
    description TEXT,
    detected_at TIMESTAMP,
    resolved BOOLEAN
);
```

## ✅ Summary

### Process Analytics Мониторит:

**НЕ:**
- ❌ CPU usage
- ❌ Memory usage
- ❌ Disk I/O
- ❌ Network traffic
- ❌ Server health

**ДА:**
- ✅ BIA Workflow execution (сколько времени, какие шаги)
- ✅ Risk Assessment Workflow execution
- ✅ Compliance Audit Workflow execution
- ✅ Любые BCM процессы
- ✅ Bottlenecks в workflows (какой шаг медленный)
- ✅ Deviations (что пошло не так)
- ✅ Patterns (как обычно выполняется)
- ✅ Performance trends (улучшается или хуже?)

---

### Аналогия:

**Prometheus** = Следит за СЕРВЕРАМИ (CPU, память)
```
"Server #3 has 80% CPU usage"
"Database has 500 queries/sec"
```

**Process Analytics** = Следит за БИЗНЕС-ПРОЦЕССАМИ (workflows)
```
"BIA Workflow took 60 minutes (expected 40)"
"Impact Analysis step is bottleneck (45 min)"
"3% of Risk Assessments fail at likelihood_analysis step"
```

---

**Роль:** Business Process Intelligence (не infrastructure monitoring!)
