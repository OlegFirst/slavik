# 🚀 BCM Platform - Quick Start Guide

## ⚡ 5-Minute Setup

### 1. 📦 Start Platform
```bash
./start-bcm-fast.sh
```

### 2. 🌐 Access URLs
- **BCM Platform**: http://localhost:8069
- **Web Portal**: http://localhost:3000  
- **Admin Panel**: http://localhost:3001
- **AI Orchestrator**: http://localhost:8000

### 3. 🔑 Default Login
- **Username**: admin
- **Password**: admin
- **Database**: bcm_platform

## 🎯 Key Features

### 🏢 BCM Modules (20)
- **Risk Management** - bcm_risk_management
- **Incident Response** - bcm_incident, bcm_incident_management
- **Business Impact Analysis** - bcm_bia (AI-powered)
- **Plans & Templates** - bcm_plans, bcm_templates
- **Training & Exercises** - bcm_training, bcm_exercise
- **Client Portal** - bcm_portal
- **Governance & Audit** - bcm_governance, bcm_audit
- **AI Foundation** - bcm_intelligent_base, bcm_base

### 🤖 AI Services
- **AI Orchestrator** - Intelligent decision automation
- **BIA Engine** - ML business impact analysis
- **Document Processor** - AI document intelligence
- **Compliance Checker** - ISO 22301 automation

### 🔌 Integrations
- **TheHive** - Security incident management
- **LMS** - Moodle, Canvas integration
- **Grafana** - Monitoring dashboards
- **BPMN** - Workflow automation
