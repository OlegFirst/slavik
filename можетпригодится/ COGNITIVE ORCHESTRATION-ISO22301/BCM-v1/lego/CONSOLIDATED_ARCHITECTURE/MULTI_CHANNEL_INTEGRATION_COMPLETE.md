## 📋 USAGE EXAMPLES

### **Web Interface Usage:**
```
1. ZIP Upload:     Drop file → Process → Download results
2. Directory:      Enter path → Analyze → Get results
3. GitHub:         Enter URL → Clone → Process → Results
```

### **CLI Tool Usage:**
```bash
# Quick analysis
./cli_tool/uop analyze /path/to/project

# Full orchestration with AI
./cli_tool/uop full /path/to/project --ai --type modernization

# GitHub repository
./cli_tool/uop analyze https://github.com/user/repo

# Directory with exclusions
./cli_tool/uop generate ./my-project --type enhancement
```

### **In-Project Service Usage:**
```python
# Install and use directly in your project
from orchestrator import analyze_project, generate_architecture

# Quick analysis
result = await analyze_project()

# Full generation
result = await generate_architecture(generation_type="enhancement")
```

### **API Integration:**
```python
# Direct API calls
import httpx

# Analyze directory
response = await client.post("/analyze-directory", json={
    "directory_path": "/path/to/project",
    "exclude_patterns": ["node_modules", ".git"]
})

# Analyze GitHub repo
response = await client.post("/analyze-github", json={
    "repository_url": "https://github.com/user/repo",
    "branch": "main"
})
```
