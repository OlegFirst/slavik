# 🎯 Workflow Intelligence: ЦЕЛИ vs ПРАВИЛА

**Ключевой вопрос**: Есть ли ЦЕЛИ или только ПРАВИЛА? И на кого они действуют?

---

## ⚠️ ПРОБЛЕМА СЕЙЧАС

Ты прав! Сейчас в Workflow Intelligence есть **только ПРАВИЛА**, но **НЕТ ЦЕЛЕЙ**:

```yaml
# ❌ Что ЕСТЬ (только правила):
bia_workflows:
  validation:
    min_rto_minutes: 15          # ПРАВИЛО: RTO не может быть меньше 15 минут
    max_rto_hours: 48            # ПРАВИЛО: RTO не может быть больше 48 часов
    require_dependencies: true   # ПРАВИЛО: Зависимости обязательны

# ✅ Чего НЕТ (целей):
bia_workflows:
  goals:
    target_completion_days: 7     # ЦЕЛЬ: Завершить BIA за 7 дней
    target_quality_score: 85      # ЦЕЛЬ: Качество BIA должно быть >85%
    target_user_satisfaction: 4.5 # ЦЕЛЬ: Удовлетворенность пользователя >4.5/5
```

## 🎯 ЧТО ТАКОЕ ЦЕЛИ vs ПРАВИЛА

### **ПРАВИЛА** (Rules) - "Что НЕЛЬЗЯ делать"

```python
# Правило - это ОГРАНИЧЕНИЕ (constraint)
# Блокирует некорректные действия

rule = {
    "type": "validation",
    "check": "rto_hours >= 1",
    "action_if_violated": "BLOCK"  # ❌ Остановить workflow
}

# Пример:
if rto_hours < 1:
    raise ValidationError("RTO cannot be less than 1 hour")
    # → Пользователь НЕ может продолжить
```

**Характеристики правил**:
- ❌ **Негативные** ("не делай X")
- 🛑 **Блокирующие** (останавливают процесс)
- 📜 **Статичные** (не меняются со временем)
- 👨‍💼 **Для пользователя** (проверяют ввод пользователя)

---

### **ЦЕЛИ** (Goals) - "К чему СТРЕМИТЬСЯ"

```python
# Цель - это ЦЕЛЕВОЕ СОСТОЯНИЕ (target)
# Направляет действия, но не блокирует

goal = {
    "type": "optimization",
    "metric": "completion_time_days",
    "target": 7,
    "action_if_not_met": "SUGGEST"  # 💡 Подсказать как улучшить
}

# Пример:
if current_day > 7:
    suggest_optimization("You're behind schedule. AI suggests: ...")
    # → Пользователь МОЖЕТ продолжить, но получает подсказку
```

**Характеристики целей**:
- ✅ **Позитивные** ("стремись к X")
- 🎯 **Направляющие** (подсказывают путь)
- 📈 **Динамические** (адаптируются к контексту)
- 🤖 **Для системы тоже** (система сама стремится к целям)

## 🤖 НА КОГО ДЕЙСТВУЮТ ПРАВИЛА?

### **Сейчас: ТОЛЬКО на ПОЛЬЗОВАТЕЛЯ**

```python
# Workflow Intelligence проверяет ВВОД ПОЛЬЗОВАТЕЛЯ:

def validate_transition(user_data):
    # Проверяем что пользователь ввел
    if not user_data.get('rto_hours'):
        raise ValidationError("User must provide RTO")  # Блокируем пользователя

    if user_data['rto_hours'] < 1:
        raise ValidationError("User entered invalid RTO")  # Блокируем пользователя

# ❌ Проблема: Система САМА не следует правилам!
```

### **Нужно: РЕКУРСИВНОЕ ПРИМЕНЕНИЕ**

#### **1. Правила для ПОЛЬЗОВАТЕЛЯ**

```python
# Пользователь создает BIA → проверяем ввод

user_rules = [
    Rule(
        id="user_001",
        name="Must fill all required fields",
        applies_to="user_input",
        validates=lambda data: all(field in data for field in ['processes', 'rto'])
    )
]
```

#### **2. Правила для СИСТЕМЫ (Workflow Intelligence)**

```python
# Workflow Intelligence САМ должен следовать правилам!

system_rules = [
    Rule(
        id="system_001",
        name="Workflow Intelligence must complete state transition in <5s",
        applies_to="workflow_intelligence",
        validates=lambda metrics: metrics['transition_time'] < 5.0,
        action_if_violated="ESCALATE_TO_INFRASTRUCTURE_COORDINATOR"
    ),

    Rule(
        id="system_002",
        name="Workflow Intelligence must not lose state",
        applies_to="workflow_intelligence",
        validates=lambda state: state['temporal_persisted'] == True,
        action_if_violated="TRIGGER_RECOVERY"
    ),

    Rule(
        id="system_003",
        name="Case Library must anonymize before storing",
        applies_to="workflow_intelligence.case_library",
        validates=lambda case: case['k_anonymity'] >= 5,
        action_if_violated="BLOCK_STORAGE"
    )
]

# Пример проверки:
async def add_case_to_library(case_data):
    # СИСТЕМА проверяет СЕБЯ:
    if not system_rules['system_003'].validate(case_data):
        # Workflow Intelligence блокирует СЕБЯ от некорректного действия
        raise SystemRuleViolation("Cannot store case: k-anonymity < 5")
        # → Кейс НЕ сохраняется
```

#### **3. Правила для ДРУГИХ КОМПОНЕНТОВ**

```python
# Workflow Intelligence проверяет ДРУГИХ!

component_rules = [

    )
]

# Пример:
async def get_ai_recommendation():
    result = await ai_foundation.query(...)

    # Проверяем что AI Foundation соблюдает правила:
    if not component_rules['comp_002'].validate(result):

        # → Продолжаем, но предупреждаем пользователя:
        result['confidence'] = 0.5  # Default
        result['warning'] = "AI recommendation quality uncertain"

    return result
```

```python
# Workflow Intelligence делает transition
state_machine.transition("IDENTIFY" → "ANALYZE")

# Workflow Intelligence проверяет СЕБЯ:
if transition_time > 5.0:
    self.escalate_performance_issue()
```

### **Сценарий 2: Workflow Intelligence сам соблюдает Goals + Rules**

```python
# Workflow Intelligence выполняет transition:

async def execute_transition(from_state, to_state, data):
    start_time = time.time()

    # ПРАВИЛО: Transition must complete in <5s
    try:
        # Выполняем переход
        result = await state_machine.transition(from_state, to_state, data)

        duration = time.time() - start_time

        # ЦЕЛЬ: target_response_time_ms = 200ms
        if duration > 0.2:
            # Цель не достигнута, но не блокируем
            logger.warning(f"Transition slow: {duration}s (target: 0.2s)")

            # System Goal: Оптимизировать
            if duration > 1.0:
                # Критично медленно → автоматическая оптимизация
                auto_optimizer.optimize_transition(from_state, to_state)

        # ПРАВИЛО: Must persist to Temporal
        if not result['temporal_persisted']:
            # КРИТИЧЕСКОЕ нарушение → откат
            raise SystemRuleViolation("State not persisted")  # ❌ БЛОКИРОВКА
            await rollback_transition()

        # ЦЕЛЬ достигнута + ПРАВИЛА соблюдены → SUCCESS
        return result

    except Exception as e:
        # ПРАВИЛО: No data loss
        # → Rollback обязателен
        await rollback_transition()
        raise

# Метрики для отслеживания целей:
metrics.track("workflow_intelligence.transition.duration_ms", duration*1000)
metrics.track("workflow_intelligence.goals.performance.achieved",
              duration < goals.system_goals.performance.target_response_time_ms)
```
