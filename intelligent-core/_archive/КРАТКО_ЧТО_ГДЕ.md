## 🔄 Как Они Работают Вместе

```
1. User Request
        ↓
2. ChiefExecutiveAI (ai_platform)
   - Анализ intent: "Calculate BIA..." → DOMAIN
        ↓
3. DomainManager (ai_platform)
   - Роутинг: BIA keywords → BIAService
        ↓
4. BIAService (bcm_offices/bia)
   - Specialist → Expert → Organ
        ↓
5. workflow_intelligence
   - StateMachine, AIContextBuilder, CaseLibrary
```
