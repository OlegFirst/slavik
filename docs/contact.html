How to Contribute

We welcome contributions from developers, BCM professionals, and organizations

Code Contributions

  1. Fork the repository on GitHub
  2. Create a feature branch: git checkout -b feature/your-feature
  3. Make your changes with clear commit messages
  4. Add tests for new functionality
  5. Ensure all tests pass: pytest
  6. Update documentation as needed
  7. Submit a pull request with detailed description

Documentation

  • Fix typos or unclear explanations
  • Add usage examples and tutorials
  • Translate documentation to other languages
  • Create video guides or screencasts
  • Write blog posts about your experience
  • Improve API documentation

Best Practices

  • Share industry-specific BIA templates
  • Contribute risk assessment scenarios
  • Provide compliance mapping for different standards
  • Share exercise scenarios and lessons learned
  • Document integration patterns with ERPs
  • Contribute to knowledge library

Bug Reports

  • Search existing issues first
  • Provide clear reproduction steps
  • Include environment details (OS, versions)
  • Add relevant logs and screenshots
  • Describe expected vs. actual behavior
  • Label appropriately (bug, enhancement, etc.)

Development Guidelines

Code Standards

  • Python: Black formatting, Ruff linting, type hints
  • TypeScript: ESLint, Prettier, strict mode
  • Git: Conventional commits (feat:, fix:, docs:)
  • Testing: 80%+ coverage required
  • Documentation: Docstrings for all public APIs
  • Security: No credentials in code, use .env

Pull Request Process

  1. Pre-submit: Run tests, linting, type checking
  2. PR Title: Clear, descriptive (50 chars max)
  3. Description: What, why, how. Link issues.
  4. Review: Address feedback promptly
  5. CI/CD: All checks must pass (tests, build)
  6. Approval: Requires 1+ maintainer approval
  7. Merge: Squash commits for clean history

Development Setup

# Clone repository
git clone https://github.com/yourusername/AI-Platform-ISO
cd AI-Platform-ISO

# Install pre-commit hooks
pip install pre-commit
pre-commit install

# Setup backend development
cd platform-services/bia-service
python -m venv venv
source venv/bin/activate  # or `venv\Scripts\activate` on Windows
pip install -r requirements.txt
pip install -r requirements-dev.txt

# Setup frontend development
cd ../../interface/web-app
npm install

# Run tests
pytest  # Backend
npm test  # Frontend

# Start development
docker-compose up -d  # Infrastructure
uvicorn main:app --reload  # Backend
npm run dev  # Frontend
