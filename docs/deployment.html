Deployment Guide

4-phase phased startup strategy for zero-conflict deployment

Deployment Strategy: Bottom-Up Approach

Launch services layer by layer to avoid port conflicts and dependency issues

Phase 1

Infrastructure Layer

PostgreSQL, Redis, RabbitMQ, Qdrant

Time: 5 minutes

Phase 2

Platform Services

BIA, Risk, Compliance, etc.

Time: 10 minutes

Phase 3

Intelligent Core

AI modules, workflow intelligence

Time: 10 minutes

Phase 4

Interface Layer

Web app, API gateway

Time: 5 minutes

Phase 1: Infrastructure Layer

Start the foundation services first (5 minutes)

Docker Compose Launch

# Start all infrastructure services
docker run -d --name postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=bcm_platform \
  -p 5432:5432 \
  postgres:15

docker run -d --name redis \
  -p 6379:6379 \
  redis:7

docker run -d --name rabbitmq \
  -p 5672:5672 \
  -p 15672:15672 \
  rabbitmq:3-management

docker run -d --name qdrant \
  -p 6333:6333 \
  qdrant/qdrant

# Verification
docker ps | grep -E "postgres|redis|rabbitmq|qdrant"
sleep 10  # Wait for services to be ready

Health Checks

# PostgreSQL
psql -h localhost -U postgres -d bcm_platform -c "SELECT 1;"

# Redis
redis-cli ping

# RabbitMQ
curl http://localhost:15672/

# Qdrant
curl http://localhost:6333/

Ports Used

  • 5432: PostgreSQL
  • 6379: Redis
  • 5672: RabbitMQ (AMQP)
  • 15672: RabbitMQ (UI)
  • 6333: Qdrant
  • 9090: Prometheus (optional)
  • 3001: Grafana (optional)

Phase 2: Platform Services

Launch BCM services on ports 8001-8012 (10 minutes)

Start Essential Services

# Required services (6 core services)
cd /path/to/AI-Platform-ISO/platform-services

# BIA Service (Port 8001)
cd bia-service && uvicorn main:app --host 0.0.0.0 --port 8001 &

# Risk Service (Port 8002)
cd ../risk-service && uvicorn main:app --host 0.0.0.0 --port 8002 &

# Compliance Service (Port 8003)
cd ../compliance-service && uvicorn main:app --host 0.0.0.0 --port 8003 &

# Governance Service (Port 8004)
cd ../governance-service && uvicorn main:app --host 0.0.0.0 --port 8004 &

# Documents Service (Port 8005)
cd ../documents-service && uvicorn main:app --host 0.0.0.0 --port 8005 &

# Validation Service (Port 8006)
cd ../validation-service && uvicorn main:app --host 0.0.0.0 --port 8006 &

# Verification
lsof -i :8001-8006 | grep LISTEN

Environment Variables

# .env file for each service
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/bcm_platform
REDIS_URL=redis://localhost:6379
RABBITMQ_URL=amqp://guest:guest@localhost:5672
ANTHROPIC_API_KEY=your_key_here
JWT_SECRET=your_secret_here
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_key

Service Health Check

# Check all services
for port in {8001..8006}; do
  echo "Checking port $port:"
  curl http://localhost:$port/health
done

# Alternative: Check API docs
open http://localhost:8001/docs

Phase 3: Intelligent Core

Launch AI modules (10 minutes, optional)

Start AI Modules

cd /path/to/AI-Platform-ISO/intelligent-core

# AI Foundation (Core)
cd ai-foundation && python main.py --port 8020 &

# Workflow Intelligence (Port 8037)
cd ../workflow_intelligence && python main.py --port 8037 &

# Expertise Center (Port 8036)
cd ../expertise-center && python main.py --port 8036 &

# Predictive Analytics (Port 8031)
cd ../predictive && python main.py --port 8031 &

# Community Intelligence (Port 8038)
cd ../community_intelligence && python main.py --port 8038 &

# Event Intelligence (Port 8039)
cd ../event_intelligence && python main.py --port 8039 &

AI Module Dependencies

AI modules require Qdrant (port 6333) for vector storage and Redis (port 6379) for caching. Ensure Phase 1 completed successfully before starting these modules.

Phase 4: Interface Layer

Launch frontend and API gateway (5 minutes)

API Gateway

cd /path/to/AI-Platform-ISO/infrastructure/gateway

# Start gateway on port 8080
uvicorn main:app --host 0.0.0.0 --port 8080 &

# Verify
curl http://localhost:8080/health

Web Application

cd /path/to/AI-Platform-ISO/interface/web-app

# Install dependencies (first time only)
npm install

# Start development server
npm run dev

# Production build
npm run build && npm start

Access the Platform

  • Web App: http://localhost:3000
  • API Gateway: http://localhost:8080
  • API Documentation: http://localhost:8080/docs
  • RabbitMQ UI: http://localhost:15672 (guest/guest)
  • Prometheus: http://localhost:9090 (if running)
  • Grafana: http://localhost:3001 (if running)

Production Deployment

Kubernetes deployment with high availability

Kubernetes Setup

# Create namespace
kubectl create namespace bcm-platform

# Deploy infrastructure
kubectl apply -f k8s/infrastructure/

# Deploy services
kubectl apply -f k8s/services/

# Deploy intelligent core
kubectl apply -f k8s/intelligent-core/

# Deploy interface
kubectl apply -f k8s/interface/

# Check status
kubectl get pods -n bcm-platform

Scaling Configuration

# Horizontal Pod Autoscaler
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: bia-service-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: bia-service
  minReplicas: 2
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 70

Environment Configuration

Use Kubernetes Secrets for sensitive data:

# Create secrets
kubectl create secret generic db-credentials \
  --from-literal=url=postgresql://user:pass@host:5432/db \
  -n bcm-platform

kubectl create secret generic api-keys \
  --from-literal=anthropic-key=sk-ant-... \
  --from-literal=jwt-secret=... \
  -n bcm-platform

# Reference in deployment
env:
  - name: DATABASE_URL
    valueFrom:
      secretKeyRef:
        name: db-credentials
        key: url

Troubleshooting

Port Conflicts

# Find process using port
lsof -i :8001

# Kill process
kill -9 

# Use alternative port
uvicorn main:app --port 8101

Service Not Starting

# Check logs
tail -f logs/service.log

# Verify environment
cat .env

# Test database connection
psql -h localhost -U postgres

Database Issues

# Check PostgreSQL
docker logs postgres

# Reset database
docker rm -f postgres
# Then restart Phase 1

# Run migrations
alembic upgrade head

Network Issues

# Check Docker network
docker network ls
docker network inspect bridge

# Ping services
curl http://localhost:8001/health

# Check DNS
nslookup localhost

Shutdown Procedure

Graceful Shutdown (Reverse Order)

# Stop interface
pkill -f "npm start"
pkill -f "uvicorn.*8080"

# Stop intelligent core
pkill -f "python main.py --port 80"

# Stop platform services
pkill -f "uvicorn main:app --port 800"

# Stop infrastructure
docker stop postgres redis rabbitmq qdrant
docker rm postgres redis rabbitmq qdrant

# Verify all stopped
docker ps
lsof -i :3000,8080,5432,6379
