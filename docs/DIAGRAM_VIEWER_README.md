# Interactive Diagram Viewer

## Overview

Интерактивный просмотрщик диаграмм позволяет пользователям детально изучать все Mermaid диаграммы и блок-схемы на сайте. При клике на любую диаграмму она открывается в полноэкранном режиме с возможностью масштабирования и перемещения.

## Возможности

- **🔍 Полноэкранный просмотр**: Диаграммы открываются в модальном окне во весь экран
- **➕ Масштабирование**: Увеличение и уменьшение от 50% до 500%
- **👆 Перемещение (Pan)**: Перетаскивание диаграммы для просмотра разных частей
- **⌨️ Клавиатурные сокращения**: Быстрое управление с клавиатуры
- **📱 Мобильная поддержка**: Работает на всех устройствах, включая сенсорные экраны

## Как использовать

### Открытие диаграммы
1. Наведите курсор на любую диаграмму
2. Появится подсказка "🔍 Click to view full size"
3. Кликните на диаграмму для открытия в полноэкранном режиме

### Управление

#### С помощью кнопок
- **+** (плюс) - Увеличить масштаб
- **−** (минус) - Уменьшить масштаб
- **↻** (стрелка) - Сбросить вид (100%, центр)
- **×** (крестик) - Закрыть просмотрщик

#### Клавиатурные сокращения
- `+` или `=` - Увеличить масштаб
- `-` или `_` - Уменьшить масштаб
- `R` - Сбросить вид
- `Esc` - Закрыть просмотрщик

#### Мышь
- **Колесо мыши** - Масштабирование
- **Клик и перетаскивание** - Перемещение по диаграмме

#### Сенсорный экран
- **Жест перетаскивания** - Перемещение по диаграмме
- **Двойной тап** - (в разработке)

### Архитектура

```javascript
class DiagramViewer {
  // Основные свойства
  scale: number;           // Текущий масштаб (0.5 - 5.0)
  translateX: number;      // Смещение по X
  translateY: number;      // Смещение по Y
  isPanning: boolean;      // Флаг перемещения

  // Методы
  init()                   // Инициализация
  open(element)            // Открыть диаграмму
  close()                  // Закрыть просмотрщик
  zoom(direction)          // Изменить масштаб
  resetView()              // Сбросить вид
  pan(event)               // Переместить диаграмму
}
```

### Автоматическая инициализация

Просмотрщик автоматически находит все элементы с классами:
- `.mermaid`
- `.mermaid-container pre.mermaid`

И добавляет к ним обработчики событий.

## Стилизация

### Цветовая схема
Использует переменные из `unified_styles.css`:
- `--primary-color`: Основной цвет кнопок
- `--error`: Цвет кнопки закрытия
- `--secondary-color`: Цвет кнопки сброса

### Настройка
Для изменения внешнего вида редактируйте CSS переменные:

```css
.diagram-viewer-btn {
  background: var(--primary-color);  /* Изменить цвет */
  width: 40px;                       /* Размер кнопки */
  border-radius: 6px;                /* Скругление */
}
```

## Примеры использования

### Добавление на новую страницу

1. Убедитесь, что подключен `unified_styles.css`:
```html
<link rel="stylesheet" href="assets/unified_styles.css">
```

2. Добавьте скрипт перед `</body>`:
```html
<script src="assets/diagram-viewer.js"></script>
</body>
```

3. Используйте класс `.mermaid` для диаграмм:
```html
<div class="mermaid">
graph TD
    A[Start] --> B[End]
</div>
```

### Программное управление

```javascript
// Получить экземпляр
const viewer = window.diagramViewer;

// Открыть конкретную диаграмму
const diagram = document.querySelector('.mermaid');
viewer.open(diagram);

// Закрыть
viewer.close();

// Изменить масштаб
viewer.zoom(1);  // Увеличить
viewer.zoom(-1); // Уменьшить

// Сбросить
viewer.resetView();
```
