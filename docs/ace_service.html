Three Core Components

1. GENERATOR - Enhanced Context Provider

Purpose: Generate enhanced context by retrieving and enriching base context with accumulated playbook knowledge

Input:

{
  "task_type": "scenario_generation_L1",
  "base_context": {
    "module": "bia",
    "operation": "assess",
    "framework": "ISO_22301"
  },
  "module_name": "scenario_intelligence"
}

Output: Enhanced Context

{
  ...base_context,
  "playbook_strategies": [
    "Use structured format",
    "Include ISO mapping",
    "Add real examples"
  ],
  "known_patterns": [...],
  "domain_expertise": {...},
  "successful_examples": [...]
}

Key Insight: Generator retrieves the playbook for this task_type and enriches your context with accumulated wisdom from past executions

2. REFLECTOR - Trajectory Analyzer

Purpose: Analyze execution trajectory to extract insights about what worked and what didn't

Input: Trajectory

{
  "input_context": {...},
  "output_result": {...},
  "execution_time_ms": 1500,
  "success": true,
  "effectiveness": 0.85
}

Output: Insights

{
  "patterns_observed": [
    "Structured format improved clarity",
    "ISO mapping increased relevance"
  ],
  "improvement_suggestions": [
    "Add more real-world examples",
    "Include risk severity scale"
  ],
  "effectiveness_score": 0.85
}

Key Insight: Reflector identifies what worked well and what can be improved - the foundation for continuous learning

3. CURATOR - Playbook Evolution Manager

Purpose: Incrementally update playbook based on insights while preserving existing knowledge

Input: Insights

{
  "task_type": "scenario_generation_L1",
  "insights": {...},
  "preserve_knowledge": true
}

Output: Updated Playbook

{
  "playbook": {
    "version": 15,
    "strategies": [...new strategies...],
    "patterns": [...updated patterns...],
    "effectiveness_history": [0.82, 0.85, ...]
  },
  "changes_summary": "Added 2 strategies, refined 3 patterns"
}

Key Insight: Curator preserves successful knowledge while incrementally adding new insights - NO context collapse!

PostgreSQL Storage Schema

How ACE stores and evolves playbooks

ace_playbooks

Main table storing evolving playbooks with JSONB

Columns:
  • task_type (PK)
  • module_name
  • playbook (JSONB)
  • version
  • usage_count
  • avg_effectiveness
  • last_updated

ace_trajectory_log

Execution history and performance tracking

Columns:
  • id (PK)
  • task_type
  • trajectory (JSONB)
  • success
  • effectiveness
  • execution_time_ms
  • timestamp

ace_playbook_history

Version history and evolution tracking

Columns:
  • id (PK)
  • task_type
  • version
  • playbook_snapshot (JSONB)
  • changes_summary
  • created_at

Python Client Library

Easy integration with Python client

Option 1: Simple ace_workflow Helper

from infrastructure.ace_service.ace_client import ace_workflow

async def my_task_function(enhanced_context):
    # Your task logic here
    result = await generate_scenario(enhanced_context)
    return {
        "success": True,
        "data": result,
        "effectiveness": 0.85
    }

# ACE handles everything: generate, execute, reflect, curate
result = await ace_workflow(
    task_type="scenario_generation_L1",
    base_context={
        "module": "bia",
        "operation": "assess",
        "framework": "ISO_22301"
    },
    execute_task_fn=my_task_function,
    module_name="scenario_intelligence"
)

print(f"Task completed: {result['success']}")
print(f"ACE playbook version: {result['ace_metadata']['version']}")

Option 2: Manual Control with ACEClient

from infrastructure.ace_service.ace_client import ACEClient

ace = ACEClient()

# Step 1: Generate enhanced context
enhanced_context = await ace.generate_context(
    task_type="scenario_generation_L1",
    base_context={"module": "bia", "operation": "assess"},
    module_name="scenario_intelligence"
)

# Step 2: Execute your task
result = await my_task_function(enhanced_context)

# Step 3: Reflect on trajectory
trajectory = {
    "input_context": enhanced_context,
    "output_result": result,
    "execution_time_ms": 1500,
    "success": True,
    "effectiveness": 0.85
}

insights = await ace.reflect_on_trajectory(
    task_type="scenario_generation_L1",
    trajectory=trajectory,
    module_name="scenario_intelligence"
)

# Step 4: Curate playbook
updated_playbook = await ace.curate_playbook(
    task_type="scenario_generation_L1",
    insights=insights,
    module_name="scenario_intelligence"
)

print(f"Playbook updated to version {updated_playbook['version']}")

Research Foundation

Based on peer-reviewed research in agentic context engineering

arXiv:2510.04618 - Agentic Context Engineering

Key Findings:

  • +8-15% improvement in task effectiveness
  • Knowledge accumulation prevents context collapse
  • Evolving playbooks outperform static prompts
  • Incremental curation preserves successful patterns
  • Cross-task learning accelerates improvement

Three-Stage Framework:

  1. Generator: Retrieve and enrich context from playbook
  2. Reflector: Analyze trajectory to extract insights
  3. Curator: Incrementally update playbook

"The key insight is that context should evolve with each execution, not remain static."

ACE Service implements this framework as a production-ready centralized service for the entire AI Platform
