1. LLM Router - Multi-Model Orchestration

Intelligent routing to Claude Opus, Sonnet, Haiku, or GPT-4 based on task complexity

How It Works

LLM Router analyzes each request and automatically selects the best model:

  • Strategic Analysis → Claude Opus (most powerful, complex reasoning)
  • Content Generation → Claude Sonnet (balanced quality/speed)
  • Quick Tasks → Claude Haiku or GPT-3.5 (fast responses)
  • Embeddings → OpenAI text-embedding-3-large

Provider Priority

  1. Anthropic Claude (preferred)
  2. OpenAI GPT (fallback)
  3. Ollama (local - reserved)

Real-World Example

User Request: "Analyze my BIA results and provide recommendations"

What Happens:

  1. LLM Router detects task_type="strategic_analysis"
  2. Selects Claude Opus (complex reasoning needed)
  3. Sends system prompt + user context
  4. Returns comprehensive analysis in 8-15 seconds

Supported Models

Claude Opus 4 Claude Sonnet 3.5 Claude Haiku 3.5 GPT-4 Turbo GPT-3.5 Turbo

2. RAG Pipeline - Knowledge Retrieval

Retrieval-Augmented Generation: Semantic search + Vector DB + Reranking

What is RAG?

RAG combines vector search with LLMs to provide accurate, contextual answers grounded in your organization's knowledge base.

4 Vector Collections

  • bcm_knowledge - ISO 22301 standards, BCI guidelines
  • workflow_cases - 347+ workflow execution cases
  • documents - User-uploaded BCM documents
  • business_scenarios - 570+ usage scenarios

Hybrid Search

Combines two approaches:

  • Vector Similarity: 70% weight (semantic meaning)
  • Keyword Matching: 30% weight (exact terms)

Integration Example

# expertise-center/base_specialist.py

from ai_foundation import (
    RAGPipeline,
    LLMRouter,
    ContextBuilder
)

class BCMAdvisor(BaseSpecialist):
    def __init__(self):
        self.rag = RAGPipeline()
        self.llm = LLMRouter()
        self.context_builder = ContextBuilder()

    async def analyze(self, query, org_context):
        # 1. Build rich context
        context = await self.context_builder.build_context(
            workflow_id="wf-123",
            domain="bcm",
            additional_context=org_context
        )

        # 2. Retrieve knowledge via RAG
        knowledge = await self.rag.retrieve(
            query=query,
            context=context,
            top_k=5
        )

        # 3. Query LLM with context + knowledge
        response = await self.llm.query(
            system_prompt="You are BCM expert...",
            user_prompt=f"""
            Context: {context}
            Knowledge: {knowledge}
            Query: {query}
            """,
            task_type="strategic_analysis"
        )

        return response

Architecture Decision: Why Separate AI Foundation?

V7 Improved Architecture - Clear separation of concerns

AI Foundation

= AI Infrastructure (used by ALL)

  • RAG pipeline
  • LLM routing
  • ML models
  • Self-learning engine
  • Context builder

Provides AI capabilities as reusable infrastructure

Workflow Intelligence

= Workflow Logic Only

  • Workflow coordinator
  • PDCA cycle engine
  • Case library (347+ cases)
  • Workflow state management
  • Business process logic

Orchestrates workflows using AI Foundation

Benefits of Separation

✓ Loose Coupling

Services can use AI without depending on workflow logic

✓ Independent Scaling

AI layer scales separately from workflow engine

✓ Reusability

Same AI stack for BCM, HR, Finance domains

✓ Clear Separation

Workflow = orchestration, AI = computation
