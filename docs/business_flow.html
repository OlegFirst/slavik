Onboarding Steps

  1. Registration: User provides email, password, organization name
  2. Verification: Email confirmation link sent and verified
  3. Organization Setup: Define industry, size, country, BCM maturity
  4. Role Assignment: RBAC roles assigned (Admin, BCM Manager, Auditor, User)
  5. Context Definition: Stakeholders, scope, interested parties (ISO 4.1, 4.2)
  6. Process Identification: AI suggests industry-specific critical processes
  7. Initial BIA: Guided wizard for first Business Impact Analysis
  8. Dashboard Activation: Personalized dashboard with recommended next steps

Data Collection Methods

  • Questionnaire: AI-generated industry-specific questions
  • Interview: Structured sessions with process owners
  • Document Analysis: OCR + AI extraction from existing docs
  • Workshop: Facilitated group sessions
  • Observation: On-site process observation

BIA Outputs

  • Critical process inventory
  • RTO/RPO requirements per process
  • Dependency map (upstream/downstream)
  • Financial impact estimates (hourly/daily)
  • Resource requirements
  • Recovery priority ranking
  • Executive summary report

Risk Assessment Methods

Qualitative

5x5 matrix (likelihood × impact). Fast, suitable for initial assessment.

Quantitative (FAIR)

Financial impact calculation. Loss event frequency × magnitude.

Monte Carlo

Probabilistic simulation. 10,000+ iterations for range estimation.

Automated Incident Features

  • Event Intelligence: Pattern detection triggers automatic incident creation
  • Smart Routing: AI assigns incident commander based on type and availability
  • Plan Retrieval: Relevant BC plans auto-surfaced based on affected processes
  • Team Notification: Automated alerts via email, SMS, Slack, Teams
  • Real-time Dashboard: Live incident status, task progress, resource allocation
  • Communication Templates: Pre-approved messages for stakeholders
  • Documentation: Timeline, decisions, actions automatically logged
  • Learning Loop: Lessons learned fed back to AI for improved future responses
