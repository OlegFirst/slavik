Database Schema

PostgreSQL schema with RLS for data security

Core Tables

  • user_profiles: User accounts and metadata
  • organizations: Company information
  • organization_departments: Department structure
  • organization_processes: Business processes
  • bia_analyses: BIA records
  • bia_processes: Critical processes in BIA
  • bia_dependencies: Process dependencies

Supporting Tables

  • bia_questions: Questionnaire items
  • bia_answers: Stakeholder responses
  • bia_findings: Analysis results
  • ai_prompts: AI prompt templates
  • ai_logs: AI usage tracking
  • audit_log: All user actions

Row-Level Security (RLS)

Every table has RLS policies ensuring users can only access their organization's data. Admins see all data, managers see department data, users see assigned data. Enforced at database level for maximum security.

API Endpoints

RESTful API with automatic OpenAPI documentation

Authentication

Method Endpoint Description
POST /api/auth/register Create new user account
POST /api/auth/login Login and get JWT token
GET /api/auth/me Get current user profile

Organizations

Method Endpoint Description
POST /api/organizations Create organization
GET /api/organizations/my Get my organization
GET /api/organizations/{id} Get organization details
PATCH /api/organizations/{id} Update organization
POST /api/organizations/{id}/processes/generate-ai AI generate processes

BIA

Method Endpoint Description
POST /api/bia?org_id={id} Create BIA analysis
GET /api/bia?org_id={id} List all BIA analyses
GET /api/bia/{id} Get BIA details
POST /api/bia/{id}/processes Add process to BIA
POST /api/bia/{id}/questionnaire/generate Generate questionnaire
POST /api/bia/{id}/ai/calculate-rto AI calculate RTO/RPO

User Workflows

1. Getting Started

  1. Register account at /register
  2. Login with credentials
  3. Create organization
  4. Select industry (Healthcare, Finance, etc.)
  5. Add company size and location
  6. Dashboard activated

2. Creating BIA

  1. Click "Create New BIA"
  2. Name the analysis (e.g., "Q1 2025 BIA")
  3. Select collection method
  4. AI suggests processes for industry
  5. Review and add processes
  6. Set criticality levels

3. AI-Powered RTO/RPO

  1. Open BIA process details
  2. Click "Calculate RTO (AI)"
  3. AI analyzes industry standards
  4. Considers process criticality
  5. Returns RTO/RPO recommendations
  6. Accept or modify values

4. Questionnaire Flow

  1. Generate BIA questionnaire
  2. AI creates relevant questions
  3. Distribute to stakeholders
  4. Collect responses
  5. AI analyzes answers
  6. View findings and recommendations

Quick Start

Local Development Setup

# 1. Clone repository
git clone https://github.com/yourusername/AI-Platform-ISO
cd AI-Platform-ISO/mvp-platform

# 2. Setup backend
cd backend
cp .env.example .env
# Edit .env with your Supabase and Anthropic credentials
pip install -r requirements.txt
python main.py  # Runs on port 8888

# 3. Setup frontend (new terminal)
cd ../frontend
cp .env.local.example .env.local
# Edit .env.local: NEXT_PUBLIC_API_URL=http://localhost:8888
npm install
npm run dev  # Runs on port 3333

# 4. Access application
# Frontend: http://localhost:3333
# API Docs: http://localhost:8888/docs

Environment Variables

# Backend .env
SUPABASE_URL=https://xxx.supabase.co
SUPABASE_ANON_KEY=eyJ...
