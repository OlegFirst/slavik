## СЛАЙД 4: ЧТО ТАКОЕ BCM?

**Визуал**: Круговая диаграмма непрерывного цикла

```
                    ПОДГОТОВКА
                  /    ↑    \
                 /     |     \
            ОБУЧЕНИЕ ←─┼───→ МОНИТОРИНГ
                \      |      /
                 \     ↓     /
              ВОССТАНОВЛЕНИЕ ← РЕАГИРОВАНИЕ

         Каждый цикл делает систему СИЛЬНЕЕ
```

**Ключевые элементы** (маркированный список):
- **Управление непрерывностью деятельности (BCM)**: Систематический подход к подготовленности
- **ISO 22301**: Международный стандарт, обеспечивающий полный охват
- **Непрерывное улучшение**: Каждый кризис усиливает систему
- **Ориентированность на людей**: Персонал обучен, уверен, поддержан

**Заметки докладчика**:
- BCM — это не разовый проект
- ISO 22301 гарантирует, что ничего критического не упущено
- Доказан глобально в тысячах организаций
- Достаточно гибкий для любого медицинского контекста
